# 高校两学期模拟库

本场景设定 20,000 名虚拟本科生，按 2022、2023、2024、2025 级分配 4,700、4,850、5,050、5,400 人。同一名学生在两个学期各有一条学籍记录，因此共有 40,000 条人学期记录。对应大四、大三、大二、大一，两个学期的年级相同。

| 口径 | 第一学期 | 第二学期 |
|---|---:|---:|
| 模拟活动时间（含注册） | 2025-09-06 至 2026-01-18 | 2026-03-07 至 2026-07-12 |
| 校历正式上课日 | 2025-09-08 | 2026-03-09 |
| 在册学生 | 20,000 | 20,000 |
| 至少有一条平台事件的学生 | 12,348 | 12,814 |
| 平台事件 | 115,275 | 120,132 |

第一学期的 2025 级从 9 月 13 日起有学籍活动窗口。时间戳使用北京时间，包含 `+08:00`。日期依据公开校历设定，活动波动按模拟的学期初、考试段及周末权重生成。

学校公开资料用于选取 8 个院部、41 个专业或方向组合。班级按场景规模分配，共 503 个模拟行政班。专业权重、班数、班号、各级人数和活动均为合成设定。特色班名称与分年级专业参考以下资料。

- [武汉学院2025–2026学年校历](https://jw.whxy.edu.cn/info/1031/10464.htm)
- [武汉学院院部设置](https://www.whxy.edu.cn/ybsz.htm)
- [武汉学院2025年收费目录，按入学年列专业](https://cw.whxy.edu.cn/__local/4/58/CD/37215CC85CDF2D2F5756BF5E200_34E7C2C0_1A5B4B.pdf)
- [武汉学院特色班一览表](https://xxgk.whxy.edu.cn/info/1010/3529.htm)

## 学号

`SIM-YY9CCPPBBSS` 包含两位入学年、虚拟标记位 `9`、两位院部码、两位专业或方向码、两位班序和两位班内序号。示例中的共同位含义未确定，因此模拟数据使用明确的虚拟标记。会计学院用 `01`、信息工程学院用 `02`、会计学 ACA 班方向用 `01`、网络工程用 `13`，其余代码为模拟分配。

例如 `SIM-24901010201` 表示 2024 级、会计学院、会计学 ACA 方向、2402 班、班内序号 01。班级显示号可在不同专业中重复。用 `class_id` 或“入学年、院部、专业方向、班序”唯一定位班级。

## 文件与字段

| 文件 | 用途 |
|---|---|
| `campus-simulation.sqlite3` | 合成学生、专业方向、班级、学期、学期学籍和事件。保留 96 组既有合成问答及 476 条参考资料 |
| `student-semesters.csv` | 每名学生每学期一行，含院部、专业、方向、班级、年级、学号、在册时间和事件计数。零活动学籍也保留 |
| `platform-events.csv` | 事件级时间、学号、学期、类型、主题。预约包含预约时间与状态，打卡和演示测评包含分值 |
| `monthly-activity.csv` | 按学期、月份、类型汇总事件数及去重人数。同一学生可以出现在多个类型中 |
| `manifest.json` | 种子、来源、校验结果、行数与文件哈希 |

事件类型包括平台访问、文章阅读、情绪打卡、演示测评、聊天会话、咨询预约、树洞发布和教师留言。平台访问每个活跃人学期一条，表示首次模拟活动。聊天、树洞、留言使用事件与主题字段。打卡分值为 1–5，演示测评分值为 0–100，其他类型的分值留空。分值用于演示统计，无临床量表含义。

模拟库适用于离线统计、数据管道和压测。事件记录位于 `sim_*` 命名空间，与既有问答候选分表保存。应用运行库具有独立的账号和权限结构。

```sql
SELECT term_id, cohort, COUNT(*) AS enrolled,
       SUM(event_count > 0) AS active
FROM sim_term_activity
GROUP BY term_id, cohort
ORDER BY term_id, cohort;

SELECT term_id, occurred_at, event_type, topic, score
FROM sim_events JOIN sim_students USING(student_id)
WHERE student_no = 'SIM-24901010201'
ORDER BY occurred_at;
```

使用仓库中的 `scripts/build-campus-simulation.py`，传入已登记的合成问答 SQLite 和一个新输出目录即可复建数据库与 CSV。生成种子为 20261104。
