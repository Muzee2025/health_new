# 深度思考开关 E2E 测试用例

## 场景 1：开关切换与样式反馈
- 前置：进入学生聊天页，已登录。
- 步骤：连续点击输入区右侧“深度思考: 关/开”按钮两次。
- 断言：按钮文本与颜色在开/关之间切换，且无控制台报错。

## 场景 2：刷新后状态保持
- 前置：将开关切到“开”。
- 步骤：刷新页面。
- 断言：按钮仍显示“深度思考: 开”。

## 场景 3：会话切换后状态保持
- 前置：准备至少两个会话，开关置为“开”。
- 步骤：切换到另一个会话。
- 断言：按钮状态仍为“开”。

## 场景 4：开启状态请求携带历史
- 前置：开关置为“开”，会话内已有多轮历史消息。
- 步骤：发送一条新消息，抓包查看 `/api/advanced-ai/chat` 请求体。
- 断言：`deep_think=true` 且 `history` 非空。

## 场景 5：关闭状态不引用历史
- 前置：开关置为“关”，会话内已有多轮历史消息。
- 步骤：发送一条新消息，抓包查看 `/api/advanced-ai/chat` 请求体。
- 断言：`deep_think=false`，后端回复按单轮提示生成（不依赖历史）。

## 场景 6：开启状态主调用失败自动降级
- 前置：开关置为“开”，通过 Mock/网关注入让首个请求返回 500。
- 步骤：发送消息。
- 断言：前端提示“深度思考模式调用失败，已自动降级常规回复”，随后自动重试普通模式并成功返回。

## 场景 7：存储权限异常提示
- 前置：浏览器禁用 localStorage 或隐私模式下限制写入。
- 步骤：点击开关按钮。
- 断言：出现“无法保存深度思考设置，请检查浏览器存储权限”。

## 场景 8：首次开启欢迎浮层仅出现一次
- 前置：清理 `advanced_ai_deep_think_welcome_shown` 存储键。
- 步骤：点击开启“深度思考: 开”，关闭欢迎弹层；再关闭并重新开启。
- 断言：首次开启出现“已开启深度思考，回复将更长、更系统”弹层，第二次开启不再弹出。

## 场景 9：深度思考回复前后缀与结构校验
- 前置：开关置为“开”。
- 步骤：发送一条消息，检查 AI 回复文本。
- 断言：顶部包含 `【深度思考·耗时x.x秒】`，底部包含 `——结束·如需精简请回复‘简洁模式’`，正文包含“思考过程/扩展反思”区块。

## 场景 10：字数统计与倍数提示
- 前置：先在“关”模式下发送多条消息建立常规字数基线，再切到“开”模式。
- 步骤：发送深度思考请求。
- 断言：输入区下方出现“本回答共xxxx字，约为您平时请求的x.x倍”，且 x.x 通常大于 1。
