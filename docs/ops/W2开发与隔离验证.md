## 运行环境

完整前端工具链使用Node22.12+（22.x）、24.x或26+，推荐24.x，本机24.14；Vite可在20.19上运行，但Vitest5不支持Node20。`npm ci`按锁定依赖安装。开发服务器默认绑定127.0.0.1:5173，`/api`（含WebSocket）与`/static`同源代理到后端。生产反向代理仍需在后续部署阶段单独验证。

后端默认安装`backend/requirements.txt`，它引用轻量Web运行依赖，不隐式安装Chroma、torch或训练模型。开发测试另外安装`backend/requirements-test.txt`。本机独立venv已实际安装并执行`pip check`通过，不能据此保证其他平台安装结果。

## 身份与数据边界

启动前由操作员设置有效DATABASE_URL、随机JWT_SECRET_KEY及CORS_ALLOWED_ORIGINS；签名密钥至少32字节并拒绝占位值。真实配置不写入仓库。旧版token重新登录，新的HTTP与WebSocket共用严格v2用户ID身份。

教师权限来自独立分配关系；自由填写的advisor只作展示。已有学生不自动分配，新建学生分配给创建教师；学生仅能预约明确分配的老师。没有分配时显示空结果或不可预约状态，不默认全校可见。

应用导入不连接或自动建表。全新SQLite可使用`backend/scripts/init-empty-database.py --database <new-sqlite-file>`，仅接受不存在的目标文件，连已有空文件也拒绝；失败保留新文件供检查。现有SQLite用[安全记录](../test/W2认证与权限.md)中的独立迁移与分配工具，MySQL尚无本轮迁移支持。上面的路径是操作模板，未对任何运行库执行。

图片只接收PNG/JPEG/WebP，文档只接收PDF/非宏DOCX；单文件5MiB，三条multipart上传入口请求总量6MiB。文档不放公共静态目录，以Bearer请求下载并强制附件响应。格式、容量和压缩包检查不等于杀毒；部署仍需入口并发/超时/限速策略。

## 隔离测试

从仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-test.txt
.\.venv\Scripts\python.exe scripts/run-backend-baseline.py
npm test
npm run build
npm run assets:check
```

runner在测试收集前禁用dotenv，覆盖虚假密钥，切换到忽略的临时SQLite/工作/上传目录，强制关闭RAG。conftest拒绝绕过该入口的直接收集。Python socket/DNS连接被拒绝；Windows事件环仅在标准socketpair同步调用期间允许其当前线程的loopback唤醒通道。这是防误连保护，不是原生扩展或子进程的完整沙箱。不可把已有8000端口服务当测试依赖。

`scripts/capture-w2-ui.mjs`通过合成API验收1440与390宽业务页面，禁止连接真实后端/外部素材；`scripts/check-chart-gallery.mjs`验证八图切换与下载。可用环境变量PLAYWRIGHT_MODULE_PATH/SHARP_MODULE_PATH定位既有工具，不向工程添加浏览器依赖。正式结果和剩余风险见[门禁](../team/门禁记录.md)。

## 可选向量索引

RAG默认关闭，导入服务不创建持久索引。需要启用时，操作员应另行评审`requirements-optional.txt`、配置明确的CHROMA_DIR，并显式允许模型下载。当前只验证关闭路径及替身索引契约，没有下载训练模型或验证真实向量召回；SQL知识记录不能被描述成已成功建立向量索引。
