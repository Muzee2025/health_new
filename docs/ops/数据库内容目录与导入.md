# 数据库内容目录与导入

> owner: D / Lead ｜ version: 1.1 ｜ status: 技术验收通过 ｜ updated: 2026-10-25

## 内容范围

`backend/scripts/content-catalog.json`提供8篇项目原创的平台使用指南，覆盖科普阅读、给老师留言、预约与状态、测评记录边界、AI助手能力边界、教师跟进、隐私/匿名说明、账号与退出。每篇都登记可在仓库核对的代码路径作为实现来源。

这些内容只说明平台当前界面和数据契约，不是临床科普、诊断、治疗建议或已由校方批准的隐私政策。`engineering_reviewed`表示工程实现边界已核对，不表示医学或临床审核。目录不添加量表题目、阈值、伪造的校内时段、权威来源或外链封面。数据库文章来源统一为“心域智链·使用指南”，`source_url`和`cover_url`为空；导入阅读量始终为0。文章列表可沿用前端现有封面后备显示。

## 隔离与写入规则

工具`backend/scripts/build-content-database.py`只使用显式`--output`路径。默认计划模式只校验目录和路径，不创建数据库或文件。写入必须显式添加`--apply`，并且输出必须是父目录已存在的全新路径；既有路径（包括空文件）和符号链接均拒绝。工具没有原地写入模式。

不提供`--source`时，工具以最小隔离环境调用`backend/scripts/init-empty-database.py`创建当前应用schema，再导入文章。提供`--source`时，源必须是用户显式指定的SQLite普通文件；工具用只读SQLite连接和backup API复制到全新输出，再在副本上导入。源库不会被写入，dotenv被禁用，父进程的数据库、模型提供商和密钥变量不会传给schema初始化进程。运行时不启动服务、不连接网络或模型。

相同标题且全部受管文章字段相同的记录会跳过，保留原记录的阅读量和创建时间；相同标题但内容不同会报冲突，并回滚本次全部文章插入。目录内重复标题、外部来源/封面、来源占位字段和白名单外HTML均在创建输出前拒绝。`--verify`只读指定数据库，输出文章数、SQLite `quick_check`结果和外键违规计数，不输出行内容或个人数据。

正文限100000字符并须含可见文字，标题不得有首尾空白，错误类型和空HTML均拒绝。目录ID仅用于源文件追溯，数据库不新增ID映射表；幂等比较以标题和受管内容字段为准，不支持覆盖更新或自动识别改名。带source时保持已有schema，不把旧库自动迁移到最新。

建议先在权限受限的临时目录试运行计划模式，再创建新的隔离输出：

```bash
.venv/Scripts/python.exe backend/scripts/build-content-database.py --output tmp/content-guide-plan.sqlite3
.venv/Scripts/python.exe backend/scripts/build-content-database.py --apply --output tmp/content-guide-demo.sqlite3
.venv/Scripts/python.exe backend/scripts/build-content-database.py --verify --output tmp/content-guide-demo.sqlite3
```

若需以经授权的SQLite快照为基础，只复制到一个新的输出，不把该路径指向原库：

```bash
.venv/Scripts/python.exe backend/scripts/build-content-database.py --apply \
  --source /明确选择的只读快照.sqlite3 \
  --output /隔离目录/content-guide-copy.sqlite3
```

成功报告包含插入/跳过数、文章总数、`quick_check`及外键违规数；失败时保留新输出供检查，不自动删除或覆盖。对含业务数据的源库操作仍须使用授权的隔离副本并遵守数据保护流程。此文档和工具不会将本机验收解释为生产发布或业务审批。

## 隔离测试

使用仓库后端隔离runner执行新增测试。测试只创建临时合成SQLite，设置合成密钥、禁用dotenv/RAG，不读取现有库或配置，也不运行服务：

```bash
.venv/Scripts/python.exe scripts/run-backend-baseline.py backend/tests/test_content_catalog.py -q
```

测试覆盖目录和代码来源、计划模式无副作用、空库初始化和0阅读量、显式源备份及源哈希不变、相同内容重复导入跳过、冲突全量回滚、`--verify`只读、空文件/符号链接路径保护、重复标题和不安全HTML/来源拒绝。
