## 0. 一句话结论

**`git mv` 之后不补 manifest，`npm run assets:check` 会立刻 FAIL。** 这不是警告，是 error。

原因是 `scripts/check-assets.mjs:384-388` 的全覆盖检查：

```js
const allFiles = walk(assetsRoot).filter((p) => !isAssetMetadata(p))
for (const f of allFiles)
  if (!listed.has(path.resolve(f)))
    add(errors, 'COVERAGE_MISSING', rel(f), 'Asset file is not listed in manifest.')
```

`COVERAGE_MISSING` 进 `errors`，而 `status` 由 `errors.length` 决定（`:644`）。`walk` 递归所有子目录，新建的 `legacy/` 也在扫描范围内。

**实测基线**：`src/assets/` 下 **131 个文件 ↔ manifest 131 条**，严格一一对应，零豁免。移进 3 个文件就是 3 条 `COVERAGE_MISSING`。
