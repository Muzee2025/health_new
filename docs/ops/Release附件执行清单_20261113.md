## 1. 先纠正一条会误导决策的旧结论

《方案A执行清单》§7 第 1 条与我在群里的说法都是「移出 ZIP，clone 减约 11.5 MiB」。**这个数字对全量 clone 是错的**，我实测证伪。

### 1.1 决定性证据：blob 仍可从 HEAD 到达

该 ZIP 只被一个提交引入，且从未修改：

```
$ git log --all --oneline -- "deliverables/心域智链_高校两学期模拟库_20261104.zip"
1c4dbe6 chore(deliverables): add simulation, training and defense materials
```

- blob `5612e15a57ea88b68f0adef3403cfe8fc1460d43`，pack 内 **11,567,682 B**
- `git rev-list --objects HEAD` 仍列出它 → **REACHABLE_FROM_HEAD=YES**
- `git merge-base --is-ancestor 1c4dbe6 HEAD` → **exit 0**

`git rm --cached` 只改**索引**，不动历史。blob 永远留在 `1c4dbe6` 里，clone 照样要传。

### 1.2 三组对照实测（全部本轮新测，`--no-local` 排除硬链接）

| 场景 | `.git` 字节 | MiB | 相对基线 |
| --- | ---: | ---: | ---: |
| 全量 clone，ZIP 在跟踪 | 104,523,672 | 99.68 | — |
| 全量 clone，ZIP 已移出 | 104,522,397 | 99.68 | **−1,275 B（−0.00 MiB）** |
| 浅 clone `--depth 1`，ZIP 在跟踪 | 98,810,174 | 94.23 | — |
| 浅 clone `--depth 1`，ZIP 已移出 | 87,241,503 | 83.20 | **−11,568,671 B（−11.03 MiB）** |

**解读**：移出跟踪只对「不拉历史」的浅克隆有效。全量 clone 的 1,275 字节差值是那个提交的 tree 条目变化，可忽略。

### 1.3 这意味着什么

- 若目标是**降低 GitHub 仓库体积 / 全量 clone 成本**：本动作**无效**，只有重写历史或删 Release 后等 GitHub GC 才有用。
- 若目标是**降低 CI 与日常浅克隆成本**：**有效，11.03 MiB**。
- 若目标是**让 `deliverables/` 目录不再挂 11.4 MB 二进制**：**有效，工作树减 11,927,926 B**。

**决策前必须先说清目标是哪一个。** 我建议按「工作树减重 + 浅克隆减重」来记账，不按「仓库体积减重」记账。

## 4. 硬约束：`check-repo.py` 必须同批改（实测）

`scripts/check-repo.py:33-45` 的 `ACKNOWLEDGED_OVERSIZED` 把「超过 2 MB 但已认可」的文件按**精确路径**登记。移出跟踪后，条目仍在清单里，但文件已不在 `git ls-files` 中——这条登记变成**过期条目**。

### 4.1 我实测了三种组合

| 组合 | `oversized_files` | `check-repo.py` 结果 |
| --- | ---: | --- |
| 原样（HEAD） | 0 | **PASS，exit 0** |
| 移出 ZIP，**不改** `check-repo.py` | 0 | **PASS，exit 0**（条目变过期但不报错） |
| 移出 ZIP，**删掉 ZIP 那条**登记 | 0 | **PASS，exit 0** |
| 移出 ZIP + **两个 CSV 也移出**，且删掉三条登记 | **2** | **FAIL，exit 1** ❌ |

**第三行是关键：只要同批移出 `platform-events.csv`（17,056,369 B）和 `student-semesters.csv`（4,926,975 B），就必须连同它们的 `ACKNOWLEDGED_OVERSIZED` 条目一起删；只删 ZIP 那一条，CSV 仍被跟踪所以仍被认可，PASS；但 CSV 也移出却没删登记，就会立刻 FAIL。**

**因此本动作有两种做法，不能混：**

| 做法 | 移出对象 | `check-repo.py` 改动 |
| --- | --- | --- |
| **N1（最小）** | 只移出 ZIP 一个文件 | 删第 39 行 1 条（也可不删，不报错） |
| **N2（连带）** | ZIP + `platform-events.csv` + `student-semesters.csv` | **必须**删第 39-41 行 3 条，否则 FAIL |

N2 顺带让工作树再减 21.98 MB，但那两个 CSV 是目录交付物的正文，**移出后目录只剩 manifest/说明/monthly**，语义上不完整。**我建议只做 N1。**
