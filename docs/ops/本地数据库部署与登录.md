## 当前运行

系统入口为 `http://127.0.0.1:5173/`，本项目后端为 `http://127.0.0.1:18080`，数据库为SQLAlchemy访问的SQLite持久文件。8000原先被另一个Docker项目使用，旧Vite代理将认证请求发错服务；本轮没有停止或修改该项目。代理现在只接受本项目loopback 18080或显式隔离QA 18081，拒绝8000、外网、凭据及多余URL字段。

`backend/runtime/current.json`（Git忽略）记录本机当前部署目录。目录内 `health.db` 为活动副本、`source-backup.db` 为SQLite在线backup API生成的一致性备份、`.env` 为新服务独立配置、`process.json` 为启动进程信息，日志也在该私有目录。Windows准备工具设置目录ACL为当前用户与SYSTEM；配置值、账号及DB文件不入库。本机原 `backend/health.db`、根数据库、上传文件及原 `.env` 共8个文件哈希保持一致。

本次从21表原库建立备份再生成独立副本，仅新增空 `teacher_student_assignments` 表；原有表逐行摘要比对相同，没有创建任何师生关联。最终22表列定义/默认值/主键/索引/唯一约束/外键与当前模型比较无差异，`quick_check`通过。但备份与副本均有1条原有 `psychological_reports` 外键孤儿，未推测用户归属或删改，不能把本次验证描述为旧数据外键全绿。

## 启停与新部署

从仓库根目录启动已选择的部署：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-local-backend.ps1
npm run dev
```

后端已在运行时，启动器拒绝占用端口并保留现有进程。需要停止本项目时，应先核对私有目录的`process.json`、实际监听进程及启动路径，再由操作者停止匹配的进程；不要按端口批量杀进程或停止其他Docker容器。脚本以隐藏窗口启动，绑定loopback且禁用访问日志，不代表安装成Windows系统服务或开机自启。

新机器或另建部署时，先安装README中的Python依赖，再指定一个不存在的目录。以下两种准备方式只选一种，输出路径不得重复：

```powershell
New-Item -ItemType Directory -Force backend/runtime | Out-Null
$deploymentDirectory = Join-Path (Get-Location) ('backend/runtime/local-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
# 保留已有数据：只读源 -> 一致性备份 -> 新活动副本
.\.venv\Scripts\python.exe backend/scripts/prepare-local-database.py --source backend/health.db --output $deploymentDirectory
# 全新环境可将上一行改成 --empty --output $deploymentDirectory
powershell -ExecutionPolicy Bypass -File scripts/start-local-backend.ps1 -DeploymentDirectory $deploymentDirectory
```

新准备不会更改`current.json`，避免尚未验收的新副本自动接管。只有确认目标、结构与readiness后，操作者才应更新该本机指针。准备失败保留新输出供检查，原件不改。缺列时拒绝部署，需要单独版本化迁移；不使用旧`init_db.py`或`create_db.py`。Linux可直接运行Python准备工具与`run-local-backend.py --env-file <new-directory>/.env --port 18080`；本轮实际进程启动验证仅Windows。

启动器只从指定文件加载配置，要求SQLite绝对目标为同目录的`health.db`，清理继承的应用环境并禁用dotenv发现、RAG及模型下载；新配置不复制旧provider凭据。不要把真实配置或连接串粘贴到报告。HTTP就绪探针只返回状态/项目身份/表列是否齐备，不暴露SQL、路径或错误堆栈；更完整的结构和数据审计仍须离线完成。

## 登录修复与验证

登录支持用户名/姓名/学号，账号前后空格规范化；注册用户名按后端50字符约束，密码沿现有政策，其他资料仍选填。错误密码、限流、后端未就绪、错误代理和网络错误均有中文内联提示。异常200响应不存储token；成功注册自动进入学生端。回跳仅允许角色匹配的站内受保护路由，切页立即中止提交，迟到响应不会覆盖当前页面或会话。全部视觉沿用素材库。
