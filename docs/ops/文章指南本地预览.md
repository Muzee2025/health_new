## 当前预览入口

本机文章指南预览入口为 [http://127.0.0.1:5180/](http://127.0.0.1:5180/)。前端仅绑定 loopback，API 由同机 `18081` 后端提供。当前后端使用 `tmp/article-scaling-20261025/preview-private/health.db` 和同目录的新 `.env`；该 SQLite 副本由已确认的 0账号/8篇平台操作指南副本准备，含27张表、6个触发器、0个既有账号和0条师生分配。现有库、旧 `.env`、上传文件没有被用作本预览运行数据，也未被改动。

当前库没有登录账号，访问者可以通过注册页自行创建学生账号。测试中使用的合成 QA 账号属于另外的独立 `qa-private` 和 `qa-final-20261026` 库，不是预览账号凭据，也不能登录当前预览。当前零账号状态只描述这份库在本轮准备时的快照，不保证未来仍为零。

2026-10-26最终启动的预览后端readiness为HTTP200，但当前Windows环境存在间歇回环访问拒绝，曾使测试客户端启动失败及Vite代理返回500。页面有重新加载入口，健康检查通过不等于完整流程稳定；最新整合集成门禁仍未通过，详见[验收记录](../test/文章分页与预览验收.md)。未为此修改系统防火墙或移除出站guard。

本地预览没有配置真实模型提供商，RAG和模型下载均关闭；不含真实教师分配或专业医疗内容。用于阻止联网的 `--block-outbound` 通过 Python audit hook 阻断 socket 连接与 DNS 查询；它不是操作系统级沙箱。不要将预览视作生产环境或医疗服务。

## 停止与重启现有服务

如果预览窗口仍在运行，用启动该进程的 PowerShell 窗口按 `Ctrl+C` 停止对应进程。若它由桌面工具隐藏窗口启动，先按进程清单和完整启动路径核对后再停止该预览进程；不要按端口批量结束进程。确认 `5180` 和 `18081` 可用后，从仓库根目录分别重启后端与前端。后端读取现有的私有配置文件，但命令不会显示配置值：

```powershell
.\.venv\Scripts\python.exe backend/scripts/run-local-backend.py `
  --env-file tmp/article-scaling-20261025/preview-private/.env `
  --port 18081 --block-outbound --isolated-storage
```

在另一个 PowerShell 窗口创建或复用该目录中的临时 Vite 配置。它导入仓库既有配置，禁用 Vite `.env` 自动发现，并把开发服务器限定在 `127.0.0.1:5180`：

```powershell
$viteConfig = 'tmp/article-scaling-20261025/preview.vite.config.mjs'
@'
import config from '../../vite.config.js'
export default {
  ...config,
  envDir: false,
  server: { ...config.server, host: '127.0.0.1', port: 5180, strictPort: true },
}
'@ | Set-Content -LiteralPath $viteConfig -Encoding utf8
$env:HEALTH_BACKEND_TARGET = 'http://127.0.0.1:18081'
npm run dev -- --config $viteConfig
```

退出后可用 `Remove-Item Env:HEALTH_BACKEND_TARGET` 清除当前 PowerShell 会话里的代理变量。不要在文档、终端记录或截图中输出 `.env` 内容。不要通过停止其他项目来释放端口；若指定端口被占用，先识别监听进程及归属。

## 创建独立的新预览目录

如需保留当前指南数据并准备另一份独立库，选择一个不存在的新输出目录。`prepare-local-database.py` 对 `--source` 只读，并在新目录生成 SQLite 一致性备份、活动库、独立 `.env` 和部署摘要；拒绝覆盖已存在的输出目录。下面示例复制当前已确认的指南预览库：

```powershell
New-Item -ItemType Directory -Force tmp | Out-Null
$deploymentDirectory = Join-Path (Get-Location) ('tmp/article-preview-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
.\.venv\Scripts\python.exe backend/scripts/prepare-local-database.py `
  --source tmp/article-scaling-20261025/preview-private/health.db `
  --output $deploymentDirectory
```

若希望从空数据库开始，将 `--source <数据库路径>` 换成 `--empty`。新建完成后，启动后端时将 `--env-file` 指向 `$deploymentDirectory/.env`；前端代理只允许既有 Vite 配置支持的本项目 loopback 后端端口 `18080` 或 `18081`，运行前确认目标端口空闲，再通过 `HEALTH_BACKEND_TARGET` 明确选择。每个部署目录的 `.env`、`health.db`、`source-backup.db`、日志与上传文件应保持在各自目录内。重启同一部署时复用它自己的 `.env`，不可复制或覆盖其他目录的配置、数据库和上传内容。
