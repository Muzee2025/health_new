# 业务页面素材库统一引用

> owner: B / W2-LIB-01 ｜ version: 1.1 ｜ status: 技术验收通过 ｜ updated: 2026-10-22

本轮将业务静态视觉接入现有素材库。素材库展示页的合成数字只供示例，业务图表继续使用原 API 返回值，保留权限、空态、计算、下载与导出逻辑；本轮不读取或修改数据库。

## 单一消费入口

`src/design/library-catalog.json` 是可执行引用清单。`assets` 将业务角色映射为 manifest 的 approved ID；`icons` 记录 symbol、asset、element-plus 三种来源；`charts` 记录样式、option、CSS 来源和业务数据政策。静态检查脚本与运行时共同读取此 JSON。

```json
{
  "assets": { "brandLogo": "brand-logo-horizontal-svg" },
  "icons": {
    "assessment": { "kind": "symbol", "assetId": "icon-domain-sprite-24-svg", "symbol": "assessment" },
    "heart": { "kind": "asset", "assetId": "icon-phosphor-heart-svg" },
    "search": { "kind": "element-plus", "export": "Search", "source": "@element-plus/icons-vue", "scope": "standard-control" }
  },
  "charts": {
    "styleSource": "docs/design/chart-style.js",
    "optionSource": "docs/design/chart-options.js",
    "cssSource": "docs/design/chart-surfaces.css",
    "dataPolicy": "business-api-only"
  }
}
```

当前登记 16 个静态角色、25 个图标，合计引用 21 个 approved 素材。角色覆盖品牌、favicon、背景、陪伴插画、文章 fallback、404、报告/列表/网络空态、危机支持与默认头像。`asset-registry.js` 检查 manifest 状态、路径、来源、许可与哈希登记，未知角色与 legacy 立即拒绝；七个旧头像在 Vite glob 阶段排除，不先打包再运行时拒绝。原素材、manifest、许可与旧截图字节不改。

`LibraryIcon` 统一绘制已有八个领域 symbol、四个 Phosphor 图标和十三个 Element Plus 标准控件图标。Phosphor 使用原 SVG 的 CSS mask，继承当前文字色；symbol 使用外部 `<use>`，统一 `?url&no-inline` 防止生产构建内联后失效。Element Plus 白名单来源为本地 `@element-plus/icons-vue` 2.3.2（MIT），只经 `icon-registry.js` 显式导出。Element Plus 组件内部控件图标保持组件自身行为。树洞点赞、收藏继续由原 API 更新，保留可访问状态。

`LibraryEmpty` 在原 ElEmpty 布局中引用库内 approved 列表空、报告空、网络错误插画，透传描述、尺寸、条件与插槽。页面不再隐式使用组件库的默认空态插画。业务 emoji、树洞自绘 SVG、散落的静态路径与显式图标包导入均已收口。

## 图表与主题层级

品牌/控件使用 `src/styles/tokens.css`；科研图表使用库内 `chart-palette.json` 与 `chart-style.js`，共享 `chart-options.js` 和 `chart-surfaces.css`。`src/design/chart-registry.js` 仅为这些源提供 Vue 业务适配，不维护第二套主题。原 `business-theme.js` 保留兼容导出。

展示页与全部业务 ECharts `setOption` 共用数据无关 helper。字体、轴/网格、图例、tooltip、线宽 2.5、符号 6、条形圆角 2、面积透明度 .55、饼图边框 2 来自同一库；graphic 数值使用库的 26/600 字体角色，说明使用 12/400。共享 CSS 提供图表卡片与标题外观。Chart.js 置信度视图复用同一字体与条形外观，保留原百分比单位、回调与叠字。

helper 保留每页图型、数据、轴类型、刻度界限、单位、编码、formatter、布局与语义颜色。教师真实分配计数、情绪无样本 null、学生词频计数和预约计数不会由示例值替代。展示页继续从自己的合成数据模块读取演示值，业务没有导入该模块。

## 动态业务例外

用户上传头像、教师资料头像、文章 cover_url、文章富文本内容与合法附件地址是运行时业务数据，不锁成静态素材 ID。现有动态解析、安全下载、Bearer、HTML 净化与错误 fallback 保留。用户文字、量表题目与代码示例不作为装饰素材替换。静态 fallback 仍经注册表，不能用动态例外引入新的外部图库或 CDN。
