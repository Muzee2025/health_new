# 素材工作台升级方案

> owner: B / R2 ｜ version: 1.1 ｜ status: 待独立复核 ｜ updated: 2026-10-21

## 任务与边界

R2 输入为用户确认的「温暖、有陪伴感、偏人文」方向、W1 素材清单与既有独立展示页。唯一写入为 `library-preview.html`、同名 JS/CSS、本方案；允许的 `src/styles/base.css` 未修改。不改业务 Vue、入口、路由、API、数据库、依赖、生成器或素材清单。不提交或暂存。

## 视觉计划与自评

采用左侧安静目录与右侧素材工作区，品牌探索、素材挑选、使用场景、数据主题四段逐层展开。手机目录变为顶部横向导航，主要内容单列。标题使用 token 内本地中文宋体，正文使用本地无衬线；不用远程字体。所有标题左对齐，标志与空状态场景居中。

颜色沿用 R1 统一令牌：相伴紫 `#78558F`、深相伴紫 `#604372`、轻柔紫 `#EEE7F2`、杏光 `#E8B185`、鼠尾草 `#8BA696`、苔墨 `#29332F`。辅助底色使用同源暖纸白与浅杏色。风险和六种真实情绪字段不变。

最初以一排通用卡片承载所有内容，会削弱陪伴语气和信息层级。因此首屏改为一份支持回应的场景，品牌比较用展台，素材用可操作的开放网格，技术信息折叠进详情。仅首屏支持场景使用有特征的拱形轮廓，其他区域保持安静；不使用装饰渐变或自动入场动画。

```text
目录 | 一句话表达                      支持提示场景
     | 三种品牌方向 / 明暗与缩放 / 可复制色板
     | 搜索 + 类别 + 格式 / 结果数量 / 素材网格
     | 空报告场景                     陪伴消息场景
     | 支持趋势 / 六类情绪 / 风险分级 + 合成数据切换
```

## 实际交互

- 只读 `manifest.json` 中 approved 条目。同角色或同主文件的导出合为一组，卡片不重复铺陈所有分辨率。来源待核实的七个旧头像保留隔离说明。
- 类别、中文/英文关键词、格式组合筛选，结果实时计数；无结果时给清空入口。筛选只决定可选文件，详情可继续选择该组实际存在的格式与尺寸。
- 原生 dialog 管理模态焦点、Esc 关闭、关闭后回到开启按钮；点击背景也可关闭。键盘可以访问类别、卡片、格式、尺寸和下载。
- 预览、下载、引用路径、文件编号、尺寸与来源均来自当前所选 manifest 条目。SVG sprite 用八个 symbol 展示，反白文件配深底，不将整张 sprite 当空白图片。
- 复制先同步尝试浏览器选区复制，成功即结束；仅同步失败时等待 Clipboard API 的明确结果。等待浏览器许可期间禁用页面内所有复制入口并持续显示状态，不使用超时竞争或同时执行另一份写入。API 明确失败或不可用时显示可选中的完整路径与反馈。下载链接的本地路径与文件名随当前规格变化。
- 三候选可点击切换，正式默认标志以及两候选提供的单色/反白源可真实预览。缩放滑杆提供键盘操作。缺少任何正式变体时禁用该模式，避免用滤镜伪造文件。
- 色板点击复制 HEX。图表保留六个真实字段与低/中/高风险含义，切换 A/B 合成数据；响应减少动态偏好，数据文本可展开阅读。
- 空报告场景按钮直接打开插画详情；陪伴角色按钮跳转并筛选教师，均提供实际操作。

后续同轮 `node tmp/r2-advanced-qa.mjs` 退出 0：三方向 × 标准/单色/反白九张源均加载成功；缩放滑杆 96px 生效；实际读取系统剪贴板内容与选中头像的项目路径一致；强制 Clipboard API 拒绝且 execCommand 返回 false 时显示、聚焦、选中完整 fallback 路径；成功与失败分支均能 Esc 还焦点；推荐小符号 16px PNG 下载路径正确。检查中修复复制尚未完成就关闭弹窗时的异步焦点竞态。

### R4 独立审查后的两处修复

1. `assetUrl()` 对相对路径的每一段执行 `encodeURIComponent`，保留目录斜杠；插入预览图片、sprite use 和小标 HTML 属性时再执行属性转义。文件名或目录名中的双引号、空格、`&`、`#`、`?`、中文不再改变 URL 或 HTML 属性边界；不依赖文件名正则保护目录。
2. 删除 Clipboard API 写入与 1.5 秒超时的竞争逻辑。同步选区复制成功后不调用异步 API；同步失败时只允许一个待完成的 API 请求，等待明确成功或失败。等待时禁用路径与色板复制，并持续显示浏览器许可状态。关闭弹窗使请求 UI 结果失效，晚到结果不会还焦点或写回已关闭弹窗。此改动避免无法取消的异步写入与应用内另一份复制并行。

`node tmp/r2-review-fix-qa.mjs` 退出 0，测试没有修改真实 manifest：

- 从展示页源码提取纯函数，注入包含目录双引号、`onerror` 片段、中文、空格及 URL 保留字符的路径，核对逐段编码的精确结果；在隔离 DOM 解析预览属性后仅有 src/alt 两个属性，无 onerror 属性。
- 实际同步复制成功，读回路径一致，异步 API 调用计数为 0。
- 强制同步失败后实际 Clipboard API 成功，读回路径一致，调用计数为 1；两条成功分支关闭后均还焦点。
- 模拟浏览器许可等待超过 1800 毫秒，没有手动后备，没有第二次写入；路径按钮和六个色板按钮均禁用，状态继续提示等待许可。Esc 仍还焦点，随后完成待处理 Promise 不抢回焦点。
- 同步失败且 API 明确拒绝时才显示、聚焦、选中完整手动路径，Esc 还焦点；pageerror 为 0。

本次仅修改展示页 JS 和本方案，没有依赖、素材、清单或元数据变化。最终 `node --check docs/design/library-preview.js` 与限定范围 `git diff --check` 均退出 0。

核心操作定位：`#asset-search`、`#format-filter`、`[data-category]`、`.asset-card[data-key]`、`#asset-dialog`、`#detail-format`、`#detail-size`、`#copy-path`、`#download-asset`、`#copy-fallback`、`#fallback-path`、`#dialog-close`、`[data-concept]`、`[data-variant]`、`#logo-scale`、`[data-token]`、`#dataset-toggle`。详情文件选择以 manifest 的 id 作为 option 值。Lead 负责最终独立浏览器复核及索引登记。
