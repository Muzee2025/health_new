## 3. Report.vue 拆分方案

### 3.1 拆分维度

不按行数硬切，按**职责层**切，页面降级为纯编排器：

1. **纯函数层** → `src/services/`：情绪标签解析、置信度/Token 格式化、诊断行、执行摘要切分、打印元数据。无 Vue、无副作用，可直接单测。
2. **数据获取层** → `src/composables/`：报告拉取与轮询、说明请求、协同任务 SSE、打印载荷。持有 `reportLoadEpoch` / `reportIdentity` 竞态守卫。
3. **图表层** → 组件 + composable：ECharts 实例生命周期、增量渲染策略、`getDataURL` 导出，全部收在一个模块内，不跨组件共享实例。
4. **展示层** → 子组件：每个区块独立可渲染，props 进、事件出。
5. **页面层** → `Report.vue` 只保留区块组装、dialog 开关与跨区块事件接线。

不做的：不引入 Pinia 或新依赖；不重写 ECharts option；不改 `business.css`/token/素材；不做样式美化。
