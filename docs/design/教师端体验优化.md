# 教师端体验优化

> owner: FE-TEACHER（Luna）｜version: 1.0｜status: 实施完成，Lead整合与独立复核通过｜updated: 2026-10-24

## 范围与设计依据

输入为教师端七个已挂路由页面与《系统界面大纲》v0.4。仅修改 `src/views/teacher/` 下除 `Layout.vue` 外的七页；共享布局与 `business.css` 由前端壳代理维护。界面继续使用已登记的设计令牌、`LibraryIcon`、`LibraryEmpty` 与图表主题，不新增视觉来源、依赖、API、字段或业务流程。

本轮将教师工作台的首屏优先级调整为真实待审核预警与求助/跟进入口、预警审核历史、统计与趋势。其他页面以“清晰任务入口、可区分的加载/空/错状态、窄屏保留完整数据、键盘与标签可达”为原则，减少重复装饰并保留业务信息。

## FE-TEACHER-BROWSER 320px修正

Lead在隔离生产包检查中发现学生列表分页控件越出视口、学生详情中的干预输入区和保存按钮越出视口。按复核要求修正页面自身布局：学生分页在窄屏分行排列总数、每页数量和翻页控件，不使用横向裁切容器；学生详情两列改用`minmax(0, …)`并限制列卡片最小宽度，窄屏单列，干预输入框宽度不超过卡片，保存按钮在窄屏占满可用宽度。没有以页面/父级`overflow`隐藏来掩盖表单内容；表格仍由登记的局部滚动容器承载。

代码冻结检查：针对`StudentManagement.vue`与`StudentDetail.vue`运行`git diff --check`退出码0；未构建或启动浏览器，待Lead在重建的隔离生产包复验320px实际控件边界。

后续FE-TEACHER-BROWSER2针对release QA发现的同类问题：预约管理和干预记录分页也改为窄屏分行控件，不以横向溢出遮蔽；干预日期范围选择器改为受父栏约束的全宽控件。学生详情在手机上将返回/标题与个体导出拆成上下两段，返回文案不折行，标题区和导出按钮获得完整行宽，避免中文标题逐字窄列及按钮压扁。预约动作、导出动作、API与素材图标均未改变。该四页CSS修正仅做定向代码检查并冻结，release生产包重建后的实际控件边界仍由Lead验收。

FE-TEACHER-FINAL针对release QA继续修正：Element Plus日期范围根节点携带350px的`--el-date-editor-daterange-width`，两个日期输入各自固定为39%；移动端现在覆盖宽度变量，并让两个range input以`min-width:0`平均占用剩余宽度，分隔符保持内容宽度。Element Plus页头的真实结构是`.el-page-header__header`包住左侧返回/标题和右侧extra，因此手机断点直接将该内部header改为纵向布局，导出独占下一行；此前只设在根节点的方向规则不再依赖其内部默认结构。

Lead追加120条合成记录的分页检验前，学生管理、预约管理和干预记录三处分页均设`pager-count=5`：手机上限制单次显示的页码数，桌面仍可通过前后翻页访问全页。此轮只检查针对源码的`git diff --check`（退出码0），没有构建；最终生产包与边界验证由Lead统一完成。

## 视觉与可访问性

- 沿用登记素材库和 `business.css` 语义类；局部样式只做排版与响应式补充，没有新色值、手绘SVG、emoji或外部资源。
- 每张表保留原有列。教师工作台操作列不再固定覆盖内容；各页表格只在自身容器内横向滚动。
- 搜索/筛选控件提供可访问名称，工作区区域导航有语义标签和清晰焦点；加载状态使用`role=status`，错误信息可见并给出实际可用的重试动作。
- 移动布局将详情双栏、筛选栏和分页折叠或滚动；预约状态、审核和导出动作保留原语义。

## 未改动的关键契约

- 未改API路径、请求体、响应字段、路由、权限、数据库或角色模型；没有接真实数据、合成待办、假指标或联络承诺。
- 未把教师内部跟进摘要/结果展示给学生。首次答复冲突与审核/任务状态冲突保留提示；求助服务503继续提示未启用并允许刷新。
- 预警审核仍要求记录原因并写入历史，历史读取失败和历史原因缺失分别展示；完成跟进仍要求实际结果，取消仍要求原因。
- 单生Word导出仍走原个体endpoint；教师统计Word导出仍为明确分配范围；无可靠楼宇数据时不生成地图数据。
