# 前端布局与导航优化

> owner: Luna / FE-SHELL ｜ version: 1.0 ｜ status: 实施完成，Lead整合与独立复核通过 ｜ updated: 2026-10-24

## 目标与设计选择

心域智链服务于学生自助支持和教师跟进工作。本轮保留现有暖白、品牌紫与蓝绿图表视觉，所有颜色、圆角、字体、间距、阴影和动效值继续引用 `src/styles/tokens.css`，图表继续使用已登记的 chart surfaces。品牌 logo、头像和导航图标均从素材库调用，没有增加新素材。

桌面采用固定层级：左侧品牌与角色导航、底部账号身份，右侧页面标题和当前页操作；页面内容保持左对齐并限制阅读宽度，长表格只在自身容器内横向滚动。手机保留标题和主要操作，把全部导航收进左侧抽屉，分组在纵向展开，入口不会被一条横向滚动轨道隐藏。品牌色只用于当前入口、键盘焦点和主要操作，卡片用于需要分组的信息，避免每块内容都变成同样的浮卡。

## 实施内容

- 学生保留六组一级入口：首页、自助成长、预约咨询、智能助手、匿名树洞、我的。自助成长内含测评与科普；“我的”内含心理报告与“留言与答复”，指向已有 `/student/questions`。
- 教师保留五组一级入口：工作台、我的学生、预约管理、干预记录、内容与档案。工作台下分“风险工作台”和“求助与跟进”，分别指向已有 `/teacher/advanced-dashboard`、`/teacher/support`。
- 两套移动导航均使用原页面已有图标素材库中的标准图标。汉堡入口通过已登记的 `collection` 图标表示，抽屉关闭控件使用已登记的 `arrow-left`。打开后聚焦侧栏首个交互项；抽屉开启时主内容设置 `inert`，Tab/Shift+Tab 在侧栏交互项间循环。`Escape`、可见关闭按钮、遮罩点击和路由变化会关闭抽屉；关闭后焦点回到触发按钮。视口切换回桌面会取消 inert 并聚焦当前页入口。
- FE-SHELL-FIX2：侧栏对导航链接点击做事件委托，点击当前路由（路由值不变化）也会关闭抽屉并恢复触发按钮焦点；分组按钮不会被识别为链接，因此继续保留展开行为。
- FE-SHELL-BROWSER：独立生产包探针发现 `main.inert` 后抽屉首帧 focus 未进入侧栏。打开时改为等待 Vue 更新及最多4个动画帧；逐次检查侧栏仍打开、组件仍挂载、目标元素可见且可聚焦，成功后核验 `activeElement` 已进入侧栏。关闭、桌面视口切换和卸载均递增请求序号，使迟到聚焦失效。
- Vue Router 的当前链接状态提供 `aria-current="page"`；分组按钮使用 `aria-expanded` 和 `aria-controls`。移动端隐藏抽屉时同步设置 `aria-hidden`，触控入口至少44px。
- 本地 UI/UX Pro Max `ux` 查询“mobile navigation keyboard escape focus restoration”返回键盘操作完整、焦点顺序与视觉顺序一致、所有交互保留可见焦点，且不形成键盘陷阱；实现以原生 tab 顺序和 token 焦点环满足这些原则。
- 清除两个 Layout 内重复的旧 scoped 布局规则，统一由 `src/styles/business.css` 管理 shell 和共享内容 class。减少尾部覆盖规则；统一按钮、卡片、表单、空态、表格、阅读宽度、数字对齐和减少动态偏好。
- 页面标题使用更直接的任务名称：学生首页“我的近况”、学生留言页“留言与答复”、教师单生路由“学生档案”；列表页、路由和业务语义保持不变。
- 手机表格空态文字在可视区左对齐并换行，规则仅匹配没有素材库 `ElEmpty` 子项的普通文本；不改变 `LibraryEmpty` 排版、真实数据行的局部横向滚动或固定列。
- 页面代理可用的公共 class：`.business-page`、`.business-page--reading`、`.business-page__header`、`.business-grid`、`.business-card`、`.business-card__header`、`.business-card__body`、`.business-actions`、`.business-table-wrap`、`.business-number`、`.business-form`、`.business-empty`。既有 Element Plus 表单和卡片仍获得基础样式。
- 认证页 `.auth-page`、`.auth-story`、`.auth-form-region`、`.auth-form` 兼容样式保留，以免共享规则改动破坏登录注册布局。
