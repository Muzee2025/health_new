# 心域智链品牌升级方案

> owner: B / R1 ｜ version: 2.0 ｜ status: 已实现，待独立评审 ｜ updated: 2026-10-21

## 设计结论

推荐「相伴 / 同页同行」。两片不对称书页向内舒展，中央留出开放的路径；它既属于校园阅读的语境，也表达并肩前行与愿意倾听。标记不用医疗心形、脑网络、人头节点或无限符号。相较「拥光」的庇护空间与「知音」的对话语义，「相伴」在校园识别、16px轮廓和整套背景延展上更统一。推荐是本轮设计判断，用户仍可通过三个真实候选比较后选择。

| 候选 | 构形与含义 | 取舍 |
| --- | --- | --- |
| 相伴 | 不对称双页与开放中缝；同页同行 | 推荐默认；兼具校园与陪伴感 |
| 拥光 | 开放门廊托起叶形暖光；安心停留 | 更适合支持空间，校园含义较弱 |
| 知音 | 相向回应引号；倾听与承接 | 对话识别直接，但跨场景延展较窄 |

三者保留实质不同的剪影；「拥光」「知音」另有真实单色与反白SVG。候选比较位于 `src/assets/brand/concepts/`，推荐路径仍兼容既有 `brand-logo-horizontal/vertical/mono/reverse.svg`。字标使用系统无衬线文字，不分发字体。公开注册和权属确认由项目负责人完成，本次未作商标检索或注册。

## 色彩与字体

| 令牌 | 色值 | 用法 |
| --- | --- | --- |
| brand-600 | #604372 | 主要交互、品牌文字、单色标记 |
| brand-500 | #78558F | 次级品牌识别、图表品牌系列 |
| brand-100 | #EEE7F2 | 柔和品牌底 |
| accent-apricot | #E8B185 | 被托住的暖光、书页色；不用作小字号文字 |
| accent-sage | #8BA696 | 阅读场景的安定辅助色；不用作小字号文字 |
| surface-warm | #FCFAF7 | 展示与PPT背景 |
| gray-800 / gray-600 | #29332F / #56625C | 正文与次要文字 |

正文优先 Microsoft YaHei / PingFang SC，16px与1.6行高；展示标题与引语可使用 `font-editorial` 的本地宋体，不能把它用于密集控件或长段正文。Figma字体经实际查询，采用 Noto Sans SC Regular/Medium，未上传字体二进制。风险、成功、告警、错误与六种真实情绪的语义值保留；不能因品牌转暖而把风险误写成杏色。

## 细节与延展

推荐标记有独立彩色、单色、反白版本；16/24/32px去掉纸页高光并加宽中缝，减少压缩后粘连。favicon增加24px，其余16/32/180/512接口保留。竖版透明PNG512/1024保持兼容。

五个自制状态插画使用统一地平线、2px左右的曲线与纸页/暖光语言：报告册、资料夹、路牌、传递中的纸飞机、两把交流用椅子。插画本身不烘焙行动按钮或联系方式，页面必须给可读说明和真实行动入口。危机支持图不模拟诊断、不宣称服务响应时间，也不代替紧急服务信息。

登录背景、大屏背景与PPT底板沿用舒展书页，左侧为信息留白。原有几何头像随同源色彩再导出，不指代真人；7个legacy头像保留原字节与未核实许可状态。

## 外部素材与可追溯构建

导入4个 Phosphor Regular 图标（MIT）和 Pablo Stanley 的2幅 Open Doodles 插画（CC0-1.0）。第三方来源、作者、固定版本或抓取日期、原始SHA、本地SHA、改动与许可全文均已保留，不能把它们称为项目原创。

`docs/design/ppt-kit/upstream/` 保存经SHA校验的原始字节与完整许可，原稿以 `.svg.txt` 明确区分成品。构建从本地输入生成成品，完全不依赖 `tmp/` 或网络。Open Doodles仅将坐标精度保留至两位小数、移除XML声明/生成器注释/标签间空白，并映射杏色与正文墨色；reading-side从60495字节压到50KB以内，不放宽上限。Phosphor成品仅添加完整MIT版权许可注释，矢量路径不变；下载单个SVG也会携带许可。其上游原文件与sourceSha256保持不变，成品sha256随注释更新。第三方成品使用于通用图标和阅读/自我关怀场景，不替代品牌标记。

`src/styles/tokens.css` 仍是唯一颜色源，图表主题在运行时读取令牌，PPT色板与所有自制导出由 `scripts/build-design-assets.mjs` 派生。构建对内容一致的文件跳过写入，避免浏览器预览期间无意义重写与Windows文件占用。命令和最终数量以验收结果为准，不沿用旧99项统计。

## 验证边界

验收命令为 `node --check scripts/build-design-assets.mjs`、`node scripts/build-design-assets.mjs`、`node scripts/check-assets.mjs`，再由Lead进行前端构建、浏览器检查与独立评审。构建使用已存在sharp，通过 `SHARP_MODULE_PATH` 或 `NODE_PATH` 解析，不安装依赖。正文与语义浅底文字按WCAG 4.5:1校验；颜色仍须配可读文字。

本轮只优化独立素材库，未导入业务全局入口，不改Vue、路由、API、数据库或依赖版本。正式学校联系人、真人信息、服务边界及商标注册结果没有实际资料，未虚构填写。
