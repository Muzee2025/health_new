# 图表素材库升级方案

> owner: B / C1（gpt-6.1-sol） ｜ version: 1.0 ｜ status: 定稿 ｜ updated: 2026-10-21

## 目标与边界

本轮将素材工作台 `#charts` 从三图扩充为八图，供图表选型、视觉复用和离线导出。保留既有品牌、素材搜索、详情、复制与文件下载。仅升级素材展示，不接入业务 Vue、路由、API、数据库、全局入口或新依赖；新增预约、渠道、会话和资源字段均为设计示例，不宣称现有 API 支持。

视觉沿用柔紫、杏色与鼠尾草色；标题采用现有字体体系。主趋势占桌面八列、组成概览占四列，余图按用途分组为双列；手机按相同阅读顺序单列。主趋势、组成概览和比较图承担不同阅读任务，避免八张同权重小卡。风险与六情绪读取既有主题，语义不随装饰配色变化。图中不使用三维、装饰渐变、心理量表雷达、诊断或疗效指标。

## 八图契约

| ID | 用途 / 图形 | 编码与直接阅读 | 数据口径 |
| --- | --- | --- | --- |
| `trend` | 趋势 / 面积折线 | 日期对支持次数，零基线；总量与日均直接显示 | 一天内多次支持分别计数 |
| `emotion` | 组成 / 六情绪环形 | 环形和六项名称、百分比、条数明细 | 保留 joy、sadness、neutral、fear、anxiety、anger；总条数为分母 |
| `risk` | 比较 / 横向条形 | 低、中、高三级条数，零基线和条末数值 | 分级字段的合成记录，不对个人作判断 |
| `appointment` | 比较 / 分组柱形 | 星期对计划、完成次数，零基线及柱顶数值 | 区间内同星期合计，完成不超过计划 |
| `channel` | 组成 / 100%堆叠 | 工作日、周末各自归一；分组总量与段内百分比 | 每组以自身记录总数为分母，三渠道保留一位小数后合计100.0% |
| `heatmap` | 比较 / 热力矩阵 | 星期×时段；每格显示计划次数 | 所选区间同星期、同时段合计，不是平均或实时负载 |
| `histogram` | 分布 / 直方图 | 等宽10分钟区间对会话次数，零基线与柱顶数值 | 同一原始整数样本左闭右开分箱，另有可展开原始序列 |
| `scatter` | 关联 / 散点 | 横轴浏览次数、纵轴收藏次数；编号关联资源名称和直接数值 | 一点一份合成资源，收藏不超过浏览；无回归线和因果推断 |

每图在原生 `details` 中提供带 `caption`、列标题与行标题的数据表。读图无需悬停，图表提供中文长描述，色彩同时由位置、标签和数值补充。手机触控/键盘控件至少44px，图中文字至少12px；长表局部滚动，不撑开页面。散点资源索引在图旁显示，避免长名称挤占手机绘图区。

## 模块与数据

- `chart-demo-data.js`：纯函数 `getChartDemoData({range, sample})`，固定生成2026-09-22至2026-10-21的30天整数示例；A/B以固定偏移量区分，取末7/14/30天。返回 `period`、`daily`、`emotions`、`risks`、`appointments`、`channels`、`heatmap`、`durations`、`histogram`、`resources`。
- `chart-library.js`：拥有八个 ECharts SVG 实例、控件状态、表格、摘要、导出和生命周期；所有呈现读取同一当前数据快照。没有随机数、真实学生记录或后端请求。
- `chart-library.css`：仅作用于图表工作台；旧三图专用样式已从 `library-preview.css` 移除，原页面脚本仅调用初始化入口。

渠道百分比先计算前两段的整数千分数，第三段取1000余数，展示为一位小数百分比。直方图样本数等于支持次数总和；热力格总数等于计划预约总数；渠道总数等于支持记录总数。情绪与风险为独立示例事件序列，不混用其分母。

## URL、呈现与导出

URL参数为 `chart-use=all|trend|compare|composition|distribution|relationship`、`chart-range=7|14|30`、`chart-sample=A|B`。缺失或无效值分别回退 `all`、`14`、`A`；保留原 query 与 hash，切换使用 `pushState`，刷新及浏览器前进/后退使用同一解码规则恢复。默认八图全部显示。范围相对于固定示例截止日2026-10-21，不随系统当天变化。

主选择器：`#chart-gallery`、`#chart-use-filters [data-chart-use]`、`#chart-range`、`#chart-sample`、`[data-chart-id]`、`#chart-{id}`、`#chart-data-{id}`、`[data-chart-export]`。

八图数据规模较小，直接使用既有 ECharts 的 SVG renderer。筛选时隐藏容器不传入零尺寸；`ResizeObserver` 只重绘正宽高容器。退出页面时释放实例与监听；返回 BFCache 时保留实例并重新读取 URL。图表始终采用静态呈现，普通模式和减少动态模式均关闭全部图形动画。

SVG导出新建离屏880×380 SVG实例，读取点击时的数据快照，完成同步绘制后从真实SVG DOM序列化。外层920×550包含图名、单位、摘要、日期范围、A/B标识、口径与合成数据说明。颜色变量在导出前解析为本地色值，不依赖远程字体、外链或页面CSS。环形图和堆叠图在导出中启用完整标签或图例；散点导出直接标注资源名称。文件名为 `chart-{id}-{A|B}-{7|14|30}d.svg`；按钮有pending保护，异常在页面状态区说明。
