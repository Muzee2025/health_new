> owner: B（S3），A整合 ｜ version: 1.1 ｜ status: 定稿，已实跑并独立复核 ｜ updated: 2026-10-21

任务S3仅新增 [导出脚本](../../scripts/render-scientific-figures.py) 与本文。输入是现有 [固定合成数据](chart-demo-data.js) 和S2维护的 [共享色卡](chart-palette.json)，运行产物保存在Git忽略的 `tmp/scientific-figures/`。不接入业务接口或真实记录，不修改依赖、路由、页面或全局入口；索引、团队记录和版本化选图由Lead整合。

“SCI风格”没有统一模板。这里实现清楚的坐标与单位、标准无衬线字体、轻网格、独立分母、矢量文件和300dpi位图；它是通用科研呈现示例，不代表任何期刊投稿验收。后续如有目标期刊，应按其最终尺寸、字体与分辨率规则调整。

## 运行

已有Python中必须提供 `matplotlib`、`numpy`、`Pillow`，并能运行Node.js。脚本不会安装依赖、联网或启动LaTeX。

```powershell
py -3.14 scripts/render-scientific-figures.py --range 14 --sample A --output tmp/scientific-figures
py -3.14 scripts/render-scientific-figures.py --range 30 --sample B --style science --output tmp/scientific-figures
```

`--range`仅接受7、14、30，默认14；`--sample`仅接受A、B，默认A；`--style`默认为 `builtin`。`--output`是输出父目录，每次创建新的UTC微秒时间戳子目录，不覆盖旧产物。脚本从任何工作目录运行均能定位项目与默认输出。可用 `--node` 指定已有Node解释器、`--palette` 指定符合相同schema的色卡；缺少或损坏的色卡会明确失败，不悄悄更换hex。

`--style science` 尝试已有SciencePlots的 `science` + `no-latex`，再覆盖必要的共享配色、字体与导出参数。缺少SciencePlots时输出明确提示，并在manifest记录 `requested: science`、`effective: matplotlib-builtin` 与原因。默认内置路线不依赖SciencePlots。当前环境没有SciencePlots，未安装它，也没有将内置样式冒称SciencePlots。

复用某次输出中的快照时：

```powershell
py -3.14 scripts/render-scientific-figures.py --range 14 --sample A --input tmp/scientific-figures/20261021T125055008736Z-14d-A/input-data.json
```

`--input`仅接受本脚本生成、带synthetic schema的 `input-data.json`，并核对它与当前生成器对应范围/样例完全一致。它保留快照重放能力，同时防止换入未知真实数据；仍需Node验证当前生成器。A/B是设计样例，不是实验组或受试者分组。

## 数据剖析与图表契约

不另写一套数据生成公式。脚本通过Node子进程直接导入 `getChartDemoData({range, sample})`，一次取得A/B×7/14/30六个组合，Python只做重算、校验和绘图。UTC日历从2026-09-22至2026-10-21截取最后N日。

| 字段 | 类型与规模 | 用途与限制 |
| --- | --- | --- |
| daily.date / weekday | 连续UTC日期；7/14/30行 | 折线的真实时间顺序 |
| daily.support / channels | 非负计数、三渠道 | 各日支持活动；不等于去重人数 |
| risks | 三风险类别的区间聚合 | 按类别比较观察计数；分母独立 |
| heatmap / slots | 7工作日×4时段，共28格 | 计划预约的时段分布；不是相关性矩阵 |
| durations / histogram | 原始分钟值；8个10分钟箱 | 分布及原始值均值；不是分箱中点估算 |
| emotions / appointments / resources | 固定类别聚合 | 随六组合进行一致性校验，未增加统计推断 |

每次manifest保留原始时长最小/最大、日活动最小/最大、时长8箱计数和原始均值。本轮六组合时长记录数依次为121、120、233、248、495、527；来源函数未更改。

| 图文件 | 唯一问题 | 表达与统计口径 |
| --- | --- | --- |
| trend | 活动计数如何随日期变化？ | UTC折线+点、从0起的计数轴；连线为时间顺序，不作预测 |
| risk | 各风险类别累计多少观察？ | 横向计数条、直接标值、不同纹理；不是均值柱，无须虚构误差棒 |
| heatmap | 计划预约在周几和时段如何分布？ | 28格直接标值；共享连续色阶；色条从0到本快照最大值并显示端点 |
| histogram | 支持时长分布是什么形态？ | 0至80分钟，八箱全部左闭右开；虚线为原始记录算术均值 |
| overview | 如何一起检查四种表达和独立分母？ | 2×2教学总览；a/b/c/d与各自计数在图注对应；不是合并业务指标 |

四张独立图为7.2×4.8英寸，总览为10×8英寸。它们是可调整的通用展示尺寸，未假称目标期刊版心。字体为DejaVu Sans、正文轴标签8pt、图注最小7.2pt；英文标签避开系统CJK字体依赖。图内标明SYNTHETIC DESIGN EXAMPLE、样例、UTC来源日期、来源文件和计数非人数；不添加误差带、P值、拟合线或临床结论。

全部颜色直接读取共享JSON，风险条的纹理和直接数值、均值虚线、热图格内数字提供冗余编码。每图另存灰度预览。共享连续色阶不声称经过感知均匀性认证；跨快照色条上限会变化，应读数值和范围，不能只凭填色比较不同快照。

## 产物与审计

每次输出含 `input-data.json`、`manifest.json`；五个图各有 `.svg`、`.pdf`、`.png` 和 `-grayscale.png`，共20个图文件。独立PNG为2160×1440，总览为3000×2400，嵌入约300dpi元数据。SVG保留可编辑文字和矢量路径，无嵌入位图；PDF使用fonttype42并校验TrueType嵌入。

manifest包含UTC生成时间、输入文件/规范化数据/生成器及其主题import/脚本/色卡SHA-256、方法、维度、dpi、实际文件路径与hash、运行库版本、有效样式、六组合校验及限制。相同输入的规范化数据hash可以比较；PDF等文件可能受创建时间元数据影响，不承诺跨运行字节一致。

每次绘图内置检查：

- 独立重算八图聚合；日期连续且UTCweekday一致，渠道/支持/时长一致，预约完成≤计划，收藏≤浏览。
- 热图28格唯一、逐格与原slots一致、合计等于计划预约；八个时长箱逐箱从原记录重新计数，无丢失和重复。
- 捕获缺字warning；检查实际可见文字不超出画布。定位器生成但不绘制的越界tick不误报。
- 检查SVG存在path且无image，PDF签名/非Type3/TrueType嵌入，PNG固定像素与DPI。

自动检查不能代替目视判断标题之间的间距、灰度可读性和图例遮挡，也不等于独立评审。
