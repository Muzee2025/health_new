本轮依据用户选择“进入W2：系统加固与业务页面接入”，将已验收的温暖、人文、陪伴方向应用到业务界面。起点为 `62055a0`；开工 `git status --short` 为空。唯一写入范围为 `src/`、`public/`、`index.html` 与本文，临时浏览器检查放在 Git 忽略的 `tmp/w2-frontend/`。未暂存、提交或切换分支。

使用 `frontend-design` 与 `frontend-app-builder`，本轮为已有设计系统的业务接入，不另生成或重选品牌概念。设计依据为[品牌升级方案](品牌升级方案.md)、[素材库规范](素材库规范.md)、[科研色卡方案](科研色卡与UI方案.md)。已通过 `view_image` 对照 W1 已验收截图与本轮业务截图；本轮不是对素材工作台页面的逐像素复制。

业务布局延续原路由、表单、表格和图表的信息结构。品牌主色用柔紫与暖杏；数据绘图区为白底、深蓝/青绿/暖杏；状态仍配文字。正文采用既有无衬线字体，登录说明标题采用既有宋体字体栈，没有外网字体。

      可横向滚动的原有导航

## 客户端安全修正

### 报告 Service Worker

原 `public/sw.js` 将受保护报告缓存到不区分身份的CacheStorage并优先返回旧响应。新worker立即激活接管，仅删除已知的 `report-api-cache-v1`，不清理其他缓存，不再注册fetch拦截，因此不会离线回放其他身份的报告。真实worker检查没有设置 `serviceWorkers: block`；另以独立临时HTTP服务返回两身份合成响应，未连接真实业务后端。

### 聊天会话缓存与迟到响应

原IndexedDB名称固定为 `health_new_chat_db`，会话、消息、草稿全账号共用；网络失败还会读本地。现由挂载时捕获的登录token计算SHA-256分区，缓存客户端通过 `createPrivateChatSession` 固定会话身份，每次读写前、异步完成后均核对会话仍有效。事务在取消时abort，连接完成后关闭；卸载取消HTTP请求、SSE与重连计时，切换身份后的旧响应不能写进新会话或恢复旧草稿。

SHA-256分区是正常切账号的客户端隔离，不是加密，也不替代后端鉴权。未登录拒绝私有缓存操作；不读取、删除或自动迁移旧无归属DB。重新登录会使用新会话缓存，服务端历史可重新同步；旧离线草稿暂不自动迁移。原用户数据仍留在本机，没有执行清库或删除。

axios的迟到401只有请求携带token仍等于当前token时才清理登录；身份A的迟到失败不会清除已登录的B。

### WebSocket 与富文本

两处WS连接使用 `['access_token', token]` 子协议，URL不带凭据，服务端仅回显协议名；1008关闭不自动重连。此处本地合成浏览器拦截不代表真实后端WS联调已通过，正式协议验收由Lead完成。

文章唯一保留的 `v-html` 经过 `DOMPurify.sanitize(..., {USE_PROFILES:{html:true}})`，未放宽SVG、MathML或危险URI。AI消息和量表结果使用Vue纯文本插值并保留换行。浏览器实测恶意HTML不能执行，普通标题、强调、表格和受保护附件链接仍可用。
