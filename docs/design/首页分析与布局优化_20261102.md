# 首页分析与布局优化

> owner: UI-NOV02-DASH / Lead ｜ version: 1.1 ｜ status: 已整合并完成本机界面验证 ｜ updated: 2026-11-02

## 目标与范围

本次只调整学生首页 `src/views/student/Dashboard.vue`，并新增趋势统计函数和定向单测。沿用现有页面 token、素材图标、ECharts 注册主题与五个 dashboard API；不改后端契约，不接入新数据，不增加依赖，也不增加定时轮询。

## 布局

- 首屏先显示页面结构和每张卡片的加载、空数据或失败状态。五个现有 API 并行请求，各卡片收到结果后独立更新，单个失败不挡住其他成功内容。
- 常用行动固定为两列网格，四个按钮同宽；本地将 Element Plus 按钮间距归零，避免默认相邻按钮 margin 撑歪列宽。
- 洞察区采用两列等宽卡片网格，情绪趋势占满首行；同一行卡片由网格统一高度，窄屏收为单列。标题和辅助说明分层，量表说明不再与标题争横向空间。
- 图表实例在对应记录返回且有可绘制数据时才按需加载 `src/design/charts/basic`。共享动态导入 promise 避免重复加载；卸载时取消尚未完成的 API 请求，图表初始化等待模块时再次检查 DOM/ref 与卸载状态。

## 趋势统计口径

- 7、30、90 天均按浏览器本地日历日计算，窗口包含今天和此前 `N-1` 天；传给既有 API 的 `days` 与 `limit` 仍为所选天数。
- 优先使用后端的完整 `date_key`，再兼容完整 `date`；不从 `MM-DD` 猜年份。仅接受合法完整日期及0–100的有限数值；数值字符串可解析，null/空白/非数字/布尔值跳过，真实0保留。
- 默认近7天。按窗口内最近一次已识别的SDS/SAS工具分别统计，不把不同工具或未知来源混入均值；没有已识别来源时不生成趋势摘要。
- 同一日期只保留API响应顺序中最后一个有效值；无效值不会覆盖已有有效记录。摘要显示有记录天数、均值（1位小数）、范围和首末记录；只有至少两个日期才显示变化。
- 图表横轴为所选窗口内的逐日日期；无记录的日期用 `null` 槽位显示间断。不会补值或连接缺测段。折线保持直线、不启用平滑；横轴标签按窗口长度稀疏显示，tooltip 明示日期和记录值/无记录。
- 摘要只描述已保存数值的数量、均值、范围与首末变化，不作疾病、风险或临床推断。

## 等待与失败处理

Dashboard 的五个 GET 请求继续并行，单请求超时为 10 秒；页面卸载会 abort 仍在途的请求，切换趋势窗口会取消前一次趋势请求。错误状态按卡片显示，页首提示保留其他可用内容及重新加载入口。这里不新增轮询。
