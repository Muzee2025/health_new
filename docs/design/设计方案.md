# 心域智链素材库设计方案

> owner: B / E03 ｜ version: 1.0 ｜ status: 定稿 ｜ updated: 2026-10-20

历史说明：本文件为初始W1方案，对应 `4b2898f`。用户随后要求重做logo并优化素材库；当前品牌方向以[品牌升级方案](品牌升级方案.md)为准，工作台见[展示页升级方案](展示页升级方案.md)。下文保留原方案，不作为新版本实现声明。

## 任务与范围

W1-T1/T2/T3/T5/T6。输入为主提示词 §6、§11.3 与 ADR-003。只制作可独立验收的本地设计资产；业务入口不导入新样式。

## 视觉方案

品牌以「两条支持的弧线围合心域、节点连接彼此」为唯一核心符号。使用柔和的弧线、可识别的连接节点与少量开放空间；头像为不指代真人的几何人物，情绪只用表情及文字表达，不暗示诊断。避免照片、装饰性大数字与同形卡片堆叠。

- 核心色：联结紫 `#7B58FF`、交互深紫 `#6244E8`、支持浅紫 `#E9E6FF`、纸白 `#FFFFFF`、正文墨 `#1F2937`、安定蓝 `#2563EB`。全部颜色由 tokens.css 管理。
- 排版：系统中文无衬线，正文16px/1.6；标题32px/1.5；图例14px。无需远程字体，素材中的字标不嵌入第三方字体文件。
- 对齐：标题、说明左对齐；标志展示居中；展示页采取宽幅品牌展台、横向token带、头像标本墙与图表横排，移动端顺序堆叠。
- 情绪真实字段：joy、sadness、neutral、fear、anxiety、anger。trust/surprise仅保留历史token兼容名，不列为模型输出。

```text
┌ 品牌标志 + 心域智链             [查看目录] ┐
│ 围合的弧线 / 支持节点       用途与入库说明 │
├ token色带 / 文字对比 / 字号标尺            ┤
├ 头像标本墙               [教师 学生 情绪] ┤
├ 空状态插画 / 业务图标 / 背景              ┤
└ 同源图表：趋势 / 情绪 / 风险 + 数据切换    ┘
```

## 制作前自评与修订

最初的独立圆角卡片分类会接近通用SaaS素材站，因此改为展台和标本墙，分隔线表达分类，留白表达层级。品牌紫是明确沿用要求；只在围合符号与可交互控件上突出它，背景不添加无意义渐变。危机横幅采用平静、可行动的支持图形，不使用吓人的红色警报图像。此为执行者自评，不替代独立门禁。

## 验收与交接

验收命令：`node scripts/build-design-assets.mjs`、`node scripts/check-assets.mjs`、`npm run build`。Lead另行进行桌面/移动端展示页检查与业务合成截图。原有七个头像保持字节不变，许可未核实单列；新作品只声明项目自制，不代替法律权属确认。
