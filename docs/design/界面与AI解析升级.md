## 设计方向

**对象与用途：**学生自我观察测评和基于服务器记录的AI辅助说明。界面把流程呈现为一段可暂停的问卷，而不是医疗评估仪表盘；所有结论显示其来源、处理状态和范围。

**视觉基线：**继续引用素材库中已登记的 `brand-50/100/600/700`、`surface-warm`、`accent-sage` 与现有领域图标。不新增颜色体系、外部图片、图标或字体。正文沿用系统中文无衬线，标题用紧凑层级保持可读。

**布局概念：**先按纵向列表选择工具，再进入一张简短说明页，随后逐题作答；进度始终可见，选项采用整行按钮并保留键盘焦点，结果页将服务器值、依据、局限和AI辅助内容依次展开。窄屏改单列，主要操作保持全宽触控目标。

```text

返回列表      工具名称
              用途、作答范围、结果限制
              开始作答 / 暂不作答

进度条

[选项] [选项] [选项]

AI辅助说明：摘要 / 观察 / 可考虑 / 局限 / 来源
```

**取舍检查：**不采用“暖底+大衬线标题+统一卡片”的通用模板，重点层次由实际动作、进度和结果依据构成；暖色只沿用既有token作为低干扰底色，题目文字左对齐，说明卡片不做装饰性数据大字。结果数字不假设量表常模或风险阈值。

## 行为与契约

- `Test.vue` 按后端冻结契约提交 `{test_type, answers, submission_id}`。答案键采用现存题序0-based字符串；传原始选项值，不在浏览器反向计分或计算分数。
- 只有服务器返回带记录ID且 `test_type` 与当前工具一致后才展示结果。提交失败保留原答案与同一个 `submission_id`，明确重试；无服务器记录ID时不允许请求AI说明。
- AI请求始终提交 `{test_id}`，并核对响应的 `test_id`。离开页面、改变答案或身份变化时取消/忽略迟到回包；显示服务端状态、来源、摘要、观察、可考虑事项、局限和计分来源记录。来源记录按工程依据呈现，不称为外部文献。
- 草稿仅存当前浏览器会话的 `sessionStorage`，校验用户ID、工具、版本、24小时期限、选项集合及同次提交ID；启动时删除旧 `localStorage` 测评草稿。登出或检测到跨标签身份变化后清除草稿。
- SDS/SAS结果标示待专业复核；不显示旧硬编码诊断级别、红黄绿风险或未经核验的常模。娱乐问卷名称与描述注明用途边界，不宣称诊断、治疗或人格定型。

## 同步修复

- `Report.vue` 的报告查询只在一次处理周期内触发一次POST，之后使用指数退避的GET，最多5次重试；超时停止并提供明确的手动重试。离页和账号变化会取消请求，身份变化清除旧报告。协同分析能力只接受服务端健康接口明确返回的启用状态，未启用或读取失败时不发起协同POST。报告说明由用户点击后请求，明示本地规则/模型来源、状态和模型标识。
- 报告图表对缺失字段显示空态，不把null当成0。没有可核验的因子关系数据时不绘制关系网；分布图只使用服务器已有的数值样本。报告标注生成方式，空风险值显示“待人工评估”。
- 协同报告处理图只显示本次事件流实际回传的模型，不再用静态模型清单伪装调用轨迹；缺少置信度/token时显示暂无数据。空异常列表只说明“未发现已报告异常”，不宣称所有模型正常。
- `RiskFactorFiveDimension.vue` 对 `data_status: insufficient` 显示服务端说明；只有带provenance的 `five_dimensions` 数值才绘图。聊天区已改为复用该组件，不再从情绪标签合成风险等级或五维分数。
- 学生首页不再展示未核验的常模均值。教师个体时间线不再按客户端50/60分阈值标记“亚健康/高风险”，只展示服务器状态或待专业复核状态。教师名册改为显示待人工评估/待处理预警，干预表单不再由情绪标签推导风险和级别。
- `AIInterpretCard.vue` 区分等待、错误、无内容、本地fallback和结构化内容，不再把空文本显示成“生成中”。
