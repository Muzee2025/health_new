# 图表展台验收记录

> owner: A ｜ version: 1.0 ｜ status: 定稿 ｜ updated: 2026-10-21

本轮按用户要求更新素材工作台的图表UI并增加图形类型。起点为 `612f8cf`，分支 `codex/w1-chart-gallery`。图表仍是W1的固定合成示例，不能作为后端联调、诊断或真实用户使用证据。

## 实现与边界

由gpt-6.1-sol执行图表设计、数据和展示模块；Luna只读独立评审；Lead负责浏览器验证及整合。新增面积折线、六情绪环形、风险条形、预约分组柱、支持渠道100%堆叠、预约热力、会话时长直方、资源互动散点，共8种图表。

局部展示代码位于 `chart-library.js`、`chart-library.css` 和 `chart-demo-data.js`。品牌与风险/情绪颜色继续读取既有token；业务Vue、全局样式入口、路由、API、数据库、依赖版本和素材清单不在本轮变更范围内。

图表支持用途筛选、7/14/30天、A/B合成样例、键盘展开数据表及单图SVG下载。URL记录 `chart-use`、`chart-range`、`chart-sample` 并保留其他参数和片段；不合法值回退为全部、14天、A。图表、表格、摘要和导出取自同一快照。
