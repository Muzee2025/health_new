# 心域智链素材库规范

> owner: B / E03 / R1 ｜ version: 1.2 ｜ status: 定稿 ｜ updated: 2026-10-22

## 范围与入口

本规范覆盖 W1 新素材库。设计依据为 [设计方案](设计方案.md) 和 ADR-003；素材展示入口为 Vite 开发服务器 `/docs/design/library-preview.html`。展示页只加载本地资源与合成图表数据。W1 不修改业务 Vue、入口、路由、API、数据库或依赖版本；业务页面迁移留待 W2，不能用本库验收冒充现有业务色值及外链清零。

当前追加优化依据ADR-004及用户确认的温暖人文方向；视觉以[品牌升级方案](品牌升级方案.md)为准，原方案仅为历史参考。推荐“相伴”，保留“拥光”“知音”可比较版本。正文优先Microsoft YaHei/PingFang SC，宋体只用于展示标题与引语；品牌柔紫、杏色、鼠尾草色由token统一管理，风险与情绪语义保持不变。

## 唯一设计源

`src/styles/tokens.css` 是品牌与控件的颜色、字体、间距、圆角、阴影、字号、层级和动效令牌源。图表使用已入库的科研色板 `docs/design/chart-palette.json`，由 `chart-style.js` 提供主题；共享 `chart-options.js` 与 `chart-surfaces.css` 提供字体、线条、网格、图例与卡片外观。两层分别服务人文品牌与数据可读性，不将科研色板另复制为业务主题。语义风险保持低/中/高固定含义。`base.css` 所有规则限定在 `.xy-design`，只有展示页显式加载。W2-LIB-01 业务接入由 `src/design/` 统一消费上述源，详见[素材库统一引用](素材库统一引用.md)。

正文用 `--text-primary`、次要文字用 `--text-secondary` 配 `--surface`。标签用对应 `--success-100 / --warning-100 / --danger-100 / --info-100` 背景及 `*-text` 字色，文字对比度至少4.5:1。语义填充与情绪填充不自动等价于可读文字色。焦点环必须可见，状态同时显示文字；减少动态偏好下移除动效。

`echarts-theme.js` 的 `createChartTheme()` 在 CSS 已加载后通过 `getComputedStyle()` 读取令牌，`registerChartTheme(echarts)` 注册 `xinyu`。`PALETTE_TOKENS` 固定为品牌→语义→风险→六种真实情绪，语义与风险同义颜色重复是有意映射。每个业务指标应使用主题的 `xy.emotions[field]` / `xy.risks[level]`，不得用索引猜测字段。PPT 的 `chart-palette.json` 由同一脚本从 tokens 解析生成，不手工修改。

真实情绪字段是 `joy / sadness / neutral / fear / anxiety / anger`；`--emo-sad` 是 sadness 的兼容别名，trust 和 surprise 只为历史视觉兼容保留，不能写成模型输出或新增模型字段。色彩不能用于推断精神疾病；风险、情绪的业务解释由后端及专业人员口径决定。

## 命名、manifest与许可

使用小写类别前缀和连字符，例如 `brand-logo-horizontal.svg`、`avatar-emotion-anxiety-96.webp`。`manifest.json` 顶层包含 version/updated/assets；每项包含 id/path/type/size/usage/license/source/owner/status/sha256。path相对src/assets，type为扩展名，size为像素宽高；id由文件名及扩展名生成，全局唯一。manifest、LICENSES及.gitattributes配置不作为图片资产登记。只读遗留文件不强制改名。

上游固定输入与带MIT注释的SVG使用局部.gitattributes禁用Git文本换行转换，保留原始字节哈希。Windows全新检出与复制树内重建均已验证，见[检出记录](refinement-checkout.json)。不要把这些规则扩大到旧七项文件或改变其字节。

项目自制作标记 `LicenseRef-Project-Original`，允许项目内部复用，不代表已对外授予CC0/MIT。第三方分别保留真实MIT或CC0许可、作者、原稿来源与哈希；4枚MIT成品SVG内嵌全文许可注释，下载单文件时仍携带notice。逐项来源和适配说明见 `src/assets/LICENSES.md`。旧七项来源、作者与许可待核实，不得猜测补填。

## 新增与构建流程

1. 明确用途及唯一文件所有者，先在本规范系列表追加说明。
2. 自制SVG保持本地可编辑源，不引入远程引用、脚本、照片或未知版权内容。
3. 在 `scripts/build-design-assets.mjs` 增加源与导出规则；品牌与控件新增颜色先进入tokens；图表色彩维护已有科研色板，再从对应源取值。
4. 使用已安装的Node与sharp。支持普通模块解析、`SHARP_MODULE_PATH` 指向sharp包、或 `NODE_PATH` 指向其node_modules目录；脚本不自动安装依赖、不硬编码开发者路径。
5. 运行 `npm run assets:build`、`npm run assets:check`、`npm run build`；核对命令退出码及文件diff，Lead再作浏览器与独立门禁检查。
6. 图片引用必须给alt及显式宽高，装饰图给空alt。领域图标使用sprite的symbol id；通用交互图标使用 `library-catalog.json` 登记的既有 Element Plus 白名单（本地 @element-plus/icons-vue 2.3.2，MIT）；所有显式图标统一经 `LibraryIcon` 解析。组件内部默认控件图标由 Element Plus 提供。头像业务接入仍遵循既有头像解析逻辑。

构建会覆盖**本脚本拥有的新生成文件**、manifest、LICENSES和PPT五个生成文件，不会写入遗留七头像。不要直接手工编辑导出或生成清单；改源后重新构建。临时输出位于被Git忽略的tmp；不提交真实学生信息、密钥或未脱敏截图。

## 与主提示词的明确偏离

- 根据ADR-003，现有Vue色值、外链与三处业务图表接入属于W2；本轮以展示页三图证明主题可用，不宣称业务已迁移。
- 主提示词情绪示例含trust/surprise；本轮按真实字段修正并保留兼容token。
- 不安装svgo/sharp或改变依赖版本；使用已有运行时sharp编译原创SVG，生成脚本命名为build-design-assets.mjs，替代旧示例assets-optimize.mjs。
- 头像保留可编辑SVG及PNG512导出，四档交付为WebP；favicon选PNG四档，不另交ICO。
- 品牌PNG使用竖版居中透明方形导出；PPT logo通过引用映射复用源，不制造重复文件。
- 危机支持横幅取320×180（符合插画尺寸范围）；仅提供平静的支持图形，具体校内联系方式需真实信息确认后由业务提供。
- 遗留素材来源未核实仍为兼容保留；不通过改写许可证把它们纳入新套件。
