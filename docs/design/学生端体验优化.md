# 学生端体验优化

## 任务范围

任务 FE-STUDENT；输入为学生端八个已路由页面、素材目录和《系统界面大纲》。本记录与实现只涉及 `src/views/student/` 中除 `Layout.vue` 外的页面。API契约、身份权限、数据来源与现有业务流程保持页面原有行为。

## 设计方向

- **颜色与图形**：仅用业务token与登记素材库的 approved 图标/空态；页面不新增色值、素材、字体或外链。
- **文字**：沿用全局品牌字体；标题使用清晰中文短句，按钮直接说明动作，状态明确说明保存、加载或下一步。
- **布局**：学生首页按“行动—预约—近期洞察”纵向组织；其他页先给任务标题与主操作，再呈现表单和记录。窄屏优先单列、换行与局部横向滚动。
- **交互**：不添加未获授权的预约改期、通知、分享或人工服务承诺；不改XSS处理、跨账户隔离、报告定时器和按页图表加载边界。

## 页面调整

| 页面 | 本次方向 | 保留边界 |
| --- | --- | --- |
| Dashboard | 先呈现测评、预约、留言、助手四个真实入口与真实下一次预约；随后完整呈现原有五类图表。移除页面对常模的无依据来源描述、隐式补分和临床建议。 | 原API数据、图表选项/点击/筛选、预约取消、离页释放与图表按页加载保持。查看预约只跳已有列表，不标为改期。 |
| Appointments | 预约操作与我的记录层级清楚，加载和失败状态可见，时段卡片在窄屏可读。 | 教师分配权限、真实时段、确认/取消契约保持。 |
| Articles | 分类筛选、文章卡片和来源信息易读，卡片可键盘访问。 | 文章API、访问量事件、动态封面安全回退和详情路由保持。 |
| Questions | 留言、本人历史、分配状态和答复状态分区；说明不提供紧急响应且不承诺答复时效。 | 503 schema识别、请求取消、身份范围与接口字段保持。 |
| Test | 题目选项键盘可操作，结果去向和提交状态清楚。 | 原量表、评分、进度保存、提交及AI解析逻辑保持，不新作临床解释。 |
| Treehole | 表单、匿名公开边界、筛选和互动控件在窄屏可操作。 | 原发布/点赞/收藏/评论权限与数据契约保持。 |
| Report | 优化标题、说明和移动操作排布。 | 不改模型调用、报告分析、导出/打印/分享行为及定时器生命周期。 |
| AdvancedAiChat | 补齐会话列表键盘操作与狭屏布局细节。 | 不重写聊天、安全、流式消息、跨账户隔离和取消逻辑。 |

## 验收与限制

由Lead统一执行测试与隔离浏览器验收。本任务执行者不运行服务或浏览器。常模的出处及适用人群仍待核实；界面提示“待核实”，不将此实现视作量表专业审核或上线批准。
