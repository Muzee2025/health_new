# 学生心理测评与学校服务市场分析

> owner: APP-MARKET ｜ version: 1.0 ｜ status: 研究冻结（供申报书引用） ｜ updated: 2026-10-26

## 可融入申报书的分析正文（约1000字）

我国学生心理健康服务有明确政策牵引和广泛学校覆盖面，但学校及学生规模不能直接折算为可采购市场。教育部《2025年全国教育事业发展统计公报》显示，2025年全国有高等学校3167所，各种形式高等教育在学总规模4872.57万人，其中普通、职业本专科在校生3953.96万人；普通高中1.61万所、在校生3039.50万人；初中5.16万所、初中阶段在校生5509.34万人。学校数和学生数按教育层级分别统计：初中人数包括一贯制、完全中学等学校的初中学段，高校学生数也区分普通职业本专科与其他形式，不能视为测评系统的采购用户数。以上规模不代表心理困扰比例、测评意愿、服务覆盖率或供应商收入。[教育部《2025年全国教育事业发展统计公报》](https://www.moe.gov.cn/jyb_sjzl/sjzl_fztjgb/202607/t20260706_1442870.html)

政策方向从测评走向预防教育、转介、跟进和数据治理协同。2023—2025年专项行动计划提出研制适合中国儿童青少年的测评工具、规范量表选用和结果运用，并部署小学高年级、初中、高中及中职学生每学年至少测评一次；2025年教育部门提出年度监测、心理教师配备和分层服务体系等措施；2026年健康学校建设意见要求将心理健康融入教学服务，高校纳入培养方案、中小学加强课程建设。这些属于政策部署，不能说成学校已经建成或完成测评。采购公告可见高校单项软件、综合系统和教育部门区域测评服务等路径，但成交公告不代表已履约或全国覆盖。[2023—2025年专项行动计划](https://www.moe.gov.cn/srcsite/A17/moe_943/moe_946/202305/t20230511_1059219.html)、[2025年十条措施答记者问](https://www.moe.gov.cn/jyb_xwfb/s271/202510/t20251024_1417903.html)、[2026年健康学校建设意见](https://www.moe.gov.cn/srcsite/A17/moe_943/moe_946/202602/t20260227_1429365.html)

市场进入可优先聚焦高校。心理中心、学工、信息化和采购部门共同影响立项，任务包括测评组织、预约咨询、人工复核、转介和趋势分析。差异化可落在量表授权与适用范围、学生知情自愿、解释边界、咨询师工作流、最小权限及部署审计能力，不应宣称自动诊断或预测危机。普通高中、初中多由教育局、教科院或学校牵头，任务包括区域监测、校内支持、教师培训和专业转介；未成年人场景更需关注年龄适配、学生/监护人告知、权限、留存及转介流程。教育部指导纲要要求知情自愿、保密、谨慎使用量表、不得强迫测评并防止医学化。个人信息保护法将医疗健康信息及不满十四周岁未成年人信息列为敏感个人信息，要求特定目的、充分必要、严格保护、单独同意；处理不满十四周岁信息还须取得监护人同意并制定专门规则。[教育部中小学指导纲要](https://www.moe.gov.cn/srcsite/A06/s3325/201212/t20121211_145679.html)、[个人信息保护法](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)

市场可用变量模型：可服务学校数S×单校年度实际成交价P。S按地区、预算、既有系统、服务能力和准入条件筛选；P需匹配采购范围、服务年限、部署方式及实际成交/合同金额。现有案例只能说明采购路径，不支持行业均价、渗透率或收入承诺。准入准备包括合法量表及年龄适配依据、隐私影响评估、委托处理约定、安全材料、运维、人工复核与转介流程、试点授权和采购资质。当前项目是高校心理健康服务原型，不代表已在中小学部署、获批或具备医学诊断能力。

## 估算与建设现状的口径

- 变量估算：年度可服务市场额 = S × P。S为经地域、采购预算、服务半径、既有系统和资格条件筛选后的目标学校/采购单位数；P为同范围、同年限、同交付方式下的实际成交价。当前不填入全国统一S、P、渗透率、收入或风险率转化值。
- 政策文件表达的是制度要求和目标；公开采购结果只表明具体采购达到成交环节。没有覆盖各省市、逐校核实合同履约/验收及持续使用的数据，因此不对“全国已建成比例”做量化结论。
- 全国学校/学生统计不是心理风险统计，心理测评阳性线索也不等于临床诊断。评测输出需由受训人员结合情境复核，明确必要的转介机制。
- 面向初高中，产品团队需针对量表的年龄、语言、文化和使用目的提供依据；学校与服务方应确定学生告知、监护人参与、权限、留存/删除、异常结果人工复核和转介责任。具体适用规则需由采购方按场景审查，本分析不构成法律意见。
