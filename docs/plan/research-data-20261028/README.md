## 来源与许可

完整作者、题名、期刊、发表年、DOI与来源网址在[sources.csv](sources.csv)及[processed-data.json](processed-data.json)中。原始论文和补充材料许可按各原文标注保存，本轮选入文章为CC BY 4.0，许可链接为[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)。具体第三方材料的例外以原文信用行说明为准。研究资料包保留原始资料中的作者、版权和许可文字，规范化数值数据标记为本轮提取/转换的派生数据。

六篇原始来源：Zhou等2024，DOI `10.1186/s13034-024-00841-w`；Chen等2023，DOI `10.1186/s12888-023-05068-1`；Chen等2021，DOI `10.1038/s41398-021-01271-4`；Yang等2023，DOI `10.1186/s12888-023-04972-w`；Feng等2025，DOI `10.2196/69639`；Fitzpatrick等2017，DOI `10.2196/mental.7785`。Feng/Woebot由Europe PMC下载开放全文XML，并以期刊原文核对；JMIR公开补充DOCX由期刊API下载。

SciSpace检索和dataset列返回只作发现线索，不替代原文测量依据。检索日志见[search-log.json](search-log.json)。其中需要签章申请/加密获取的数据集没有申请、解密或纳入分析，也没有联系作者或校外人员。

## 数据处理

数值处理脚本为[scripts/process-literature-data.py](../../../scripts/process-literature-data.py)，采集脚本为[scripts/collect-literature-data.py](../../../scripts/collect-literature-data.py)。使用工作区加载器提供的Python及lxml/python-docx/pypdf，不安装额外依赖。CSV为UTF-8 BOM，空值保留为缺失，百分比统一存为0—1比例；OR、Hedges g、均值与SE分别保留不同量纲。填充原表空的组标签只是表格结构展开，不填补观测缺失。

YANG个体数据在内存读取，生成字段质量、重复序号条数及尺度诊断。BDI-II总分918/926有值，均值14.3159041394分仅描述分层访谈样本，不外推筛查总体；未把8条缺失填0。作者sampling weight和6819.85，Kish有效样本量近似356.324，仅衡量权重离散度，未包含完整分层/整群方差。没有拟合诊断预测模型或重新估计诊断患病率。

原文合并效应g/OR/CI为有来源的提取值，不是本轮重新开展的Meta分析。Excel只计算缺失率、CI宽度、期别百分点差、区间是否跨0和原表样本合计，所有数值可沿来源位置回查。

## 影响解释的限制

2020年两次独立调查的抑郁筛查比例36.6%→57.0%、焦虑19.0%→36.7%，差20.4/17.7个百分点。第二波排除重复参加者，不能说同一人的病情变化。CHEN2023的回归结局是PHQ-9≥10或GAD-7≥10任一阳性，不能改标成单独抑郁/焦虑；OR不是风险比。它与GAD-7>4的研究阈值不同，比例不可直接排名。

Zhou的Year是发表年，不能作为全国年度心理风险趋势；地区条目是研究亚组，不能解释为代表性省级人群患病率，也不与教育人数相乘。总体、学段、地区与其他综述中的研究可能重叠，不跨来源简单累加样本。

YANG主文与补充表的性别校准值不一致，部分性别标准化未独立复现；保留待作者澄清，不猜测改数。FENG2025正文15试验/1901与摘要1974、讨论16/1974不一致，补充S2的15行合计1901；消极情感的敏感性CI跨0但P<.001且k异常，该行不用于结论。Woebot部分F/P/CI疑有原文冲突，按原文列示、不用其SE冒充SD。完整清单见[source_audits.csv](source_audits.csv)。
