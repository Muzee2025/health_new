# 文献审计与AI融合建议

## 审计范围与边界

本次只读核对《心域智链申报计划书》参考文献[1]—[27]、`sci-revision-20261027/literature-evidence.md`及其JSON数据，以及新增AI方法文献的出版商或正式会议页面。重点检查文献类型是否说清、可追溯书目信息、核心方法与结果能否支持拟写结论、亚组与不确定性处理。不是系统检索或完整的引文逐条查重，也没有重新运行荟萃分析、逐篇评估439项纳入研究或全量重算31地数据。

不将SCI/JCR收录或期刊声誉当作研究正确性的替代指标；未核验任何期刊分区或收录状态。下述“同行评审”只在出版商期刊页面或NeurIPS正式会议页面可识别到论文发表载体时使用。不是对期刊质量背书。

## 主要审稿结论

1. **[25] Zhou等（2024）是出版商正式发表的系统综述与随机效应荟萃分析。** 出版商记录确认作者、题名、期刊卷18、文章号150、发表日2024-11-19和DOI `10.1186/s13034-024-00841-w`。检索截止2024-10-15，纳入439项研究、1,497,524人；总体筛查阳性合并比例26.17%（95%CI 25.00%–27.41%），I²=100%。这能支持“已纳入研究中的筛查阳性合并比例”，不能写成中国学生临床抑郁患病率或项目目标学校的风险率。
2. **证据确定性受严重异质性、工具/阈值不统一及偏倚限制。** 研究使用八类量表，作者未对同一量表的不同cut-off做亚组；Egger检验提示发表偏倚（z=−9.17，p<0.01）。作者质量评价得分3–8、中位6；439项研究中仅8项清楚描述未应答者，141项缺少CI或亚组细节。留在正文的数字应同时带上总体异质性和筛查属性。
3. **学段差异可以按原文表1报告，但不能外推为稳定年龄效应。** 高中28.23%（25.58–31.15）、本科27.72%（25.79–29.79）、初中24.15%（21.61–27.00）、小学16.97%（14.00–20.56）；原文总体亚组检验χ²=26.24、p<0.01。学段k/n不互斥，各研究可能跨亚组；高中与小学点估计相差11.26个百分点只属描述差，不能声称已做两两检验或因果比较。
4. **[26]地区表必须称研究地点亚组汇总。** Table S2原表逐行提供33个地区（含港、台、津）数据；项目使用大陆31行。地区数据不是各省代表性抽样。天津仅有一项含天津的多地研究；青海、西藏单/两项研究，估计区间及精度有限。摘要叙述对青海/西藏k值顺序与补充表S2相反，本稿按Table S2并明确保留来源不一致。不得按估计值作省域风险地图、地区因果解释或乘以教育人数估算服务需求。
5. **现有[1]—[24]中，多数是报告、政策、统计或采购证据，不是期刊论文。** 可用于限定的背景/规模/政策/采购描述，须在正文明确证据类型和原始发布机构；不应把媒体转载、政府网页托管的文件、招标成交公告改称同行评审研究。它们不能支撑平台有效性、心理问题因果关系或付费市场规模。
6. **AI建议是有范围的工作流假设，不是文献证明本产品有效。** RAG原始方法论文证明检索增强生成在通用知识密集任务中可被构造和评估；医学人类评价研究展示了评估维度与专家差距；心理健康LLM系统综述汇总当时文献并报告风险。这些来源支持“值得开展限定任务的隔离验证、展示来源、人工核对”这一研究设计，不证明心理摘要准确、安全或改善心理结局。

### 推荐正文替换段（限于可证实范围）

> 项目将人工智能限定为资料检索与记录摘要的辅助工具。统计代码先按已确认的字段字典和量表版本整理记录，并显式标注缺失与不可比项目；检索模块仅从经审核的校内资料中返回原文段落及版本信息；大模型据此起草“记录事实、资料依据、尚缺信息、待核对问题”四栏摘要，并保留对应来源。教师须对照原记录和来源逐项核验、修改或弃用，系统不由模型作出诊断、危机等级、转介决定或自动发送答复。后续先用固定合成案例评估事实支持、遗漏、引用、越界、复核修改和失败退回；只有在学校确定职责、数据与专业审阅安排后，才讨论更进一步的验证。

**AI融合逻辑：**既有测评/求助记录是数据入口；规则代码负责可复算的数字；RAG提供受控资料出处；大模型只把事实与材料组织成可读草稿；教师根据情境确认并负责回应。这种衔接是“结构化数据—来源可追溯的资料—待复核文本—人工行动”，不是把大模型当心理测评模型或专业替代者。

**对外措辞边界：**现阶段可写“拟采用/计划评估”，不可写“已验证有效、能准确识别风险、降低教师负担或改善心理健康”。模型、人群、语言、提示、语料与具体业务版本尚未冻结，故当前无法给出可复现的本产品模型性能。
