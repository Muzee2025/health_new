# SCI-LIT：儿童青少年抑郁症状筛查文献数据

## 范围与来源

本摘录只包括抑郁症状量表筛查阳性比例，不收录自杀、自伤指标，不把筛查阳性称作临床诊断。主要来源为 Zhou 等人的系统综述与随机效应荟萃分析：439项研究、1,497,524名参与者；检索至2024年10月15日，纳入年龄6–24岁。出版商原文：[Springer/BMC文章](https://link.springer.com/article/10.1186/s13034-024-00841-w)，[PMC全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11577650/)。

省级/地区级逐行值取自出版商补充材料 Additional file 4、Table S2：[补充PDF](https://media.springernature.com/original/springer-static/esm/art%3A10.1186%2Fs13034-024-00841-w/MediaObjects/13034_2024_841_MOESM4_ESM.pdf)。教育阶段取正文Table 1。完整可机读数据在同目录的 [literature-data.json](literature-data.json) 和 [literature-data.csv](literature-data.csv)。SciSpace仅用于发现与索引候选，不作为数值核验依据。

## 可用数据与精确口径

- 全部研究合并：26.17%（95%CI 25.00–27.41），I²=100%，p<0.001；439项研究、样本总数1,497,524。
- 正文Table 1的学段：小学16.97%（14.00–20.56；k=30，n=137,116，I²=99%）；初中24.15%（21.61–27.00；k=94，n=342,082，I²=100%）；高中28.23%（25.58–31.15；k=86，n=1,069,851，I²=100%）；本科27.72%（25.79–29.79；k=188，n=374,996，I²=100%）。学段总体差异检验χ²=26.24，p<0.01。高中与小学点估计相差11.26个百分点，是描述性计算；不表示因果效应，也不意味着所有学段两两差异均显著。
- Supplementary Table S2列出33个地区行（含香港、台湾、天津）。表中没有单独天津研究；天津值来自一个多地区研究。青海k=1、台湾k=1、天津k=1、内蒙古k=3、宁夏k=3；西藏k=2。地区表总体差异检验χ²=288.64，p<0.01。各地精确95%CI、I²和研究数见CSV/JSON。
- 表S2的I²为原文百分数；原文标记“--”的单研究地区保留为空并在 `i2_source_text` 写明“--”，没有推算。
- 研究发表年份范围为1988–2024；原文未给出覆盖全部纳入研究的统一现场调查时间段。不要把发表年等同调查年。不同量表（BDI、CDI、CES-D、DSRSC、HAMD、KADS、PHQ、SDS）及阈值并存；作者指出未对同一量表的不同阈值做亚组分析，不能据总值假定一个统一筛查阈值。
- 学段k/n和地区k/n为原文亚组统计，不是互斥分层。研究可能报告多个学段或多地区；样本数不能加总后当作唯一总人数。

## 正文短段建议

一项检索截至2024年10月的系统综述纳入439项研究、约149.8万名6–24岁参与者，报告抑郁症状筛查阳性的随机效应合并比例为26.17%（95%CI 25.00%–27.41%）。按学段分组的点估计从小学16.97%到高中28.23%，总体学段差异检验达到统计学显著；但研究间异质性很高（总体I²=100%），量表与阈值也不一致，因此这些汇总值用于说明不同研究中的筛查阳性比例，不作为疾病诊断率或本地人群风险预测。

## 图表建议

1. **学段点区间图**：横轴为筛查阳性比例（%），点为合并值，横线为95%CI，旁列k/n。标注总体差异检验χ²=26.24、p<0.01；不要补做或暗示未报告的两两显著性。
2. **地区森林图**：使用全部地区的点估计和95%CI，行旁显示研究数k；用研究数排序或地区名称排序，并清楚标为“研究亚组汇总”。建议不按估计着色地图；若地图展示，使用中性纳入标记与研究数/CI提示，不能表达成代表性省域风险率。必须突出青海、台湾、天津仅1项研究及天津多地区来源说明。
3. 不推荐把旧综述与2024综述的估计连成趋势线。研究对象、年代覆盖、纳入规则、量表和分析集合不同；2024文献自身的总体时间相关也未达显著（r=0.03，p=0.74）。

## 来源限制与审阅注意

- 主文Supplementary Table S2称省份/直辖市分析；其图注说明不包括澳门研究，29篇地点未注明或涉及多个省份的文章不纳入地图。图文未支持把这些研究亚组当作省级代表性抽样。
- 总体异质性I²=100%；Egger检验提示发表偏倚（z=-9.17，p<0.01）。作者称439项中仅8项清楚描述未应答者，141项（32.1%）缺少CI或亚组细节。区域样本量/研究数量与精度不同，区间不可忽略。
- 2024论文摘要按语序称青海、西藏分别有两项与一项研究；Supplementary Table S2则列为青海k=1、西藏k=2，二者计数顺序不一致。地区数据按更细的Table S2逐项摘录，并把该原文不一致保留供复核。
- 旧研究只作为背景文献，不用于时间变化比较：Gao et al. 2020大学生综述报告113项、n=185,787、28.4%（95%CI 25.7–31.2），[Scientific Reports出版商页](https://www.nature.com/articles/s41598-020-72998-1)；Lei et al. 2016大学生荟萃分析报告39项、n=32,694、23.8%（95%CI 19.9–28.5），研究发表期1997–2015，[PLOS原文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0153454)。二者均为大学生范围，与2024年6–24岁跨学段研究不可直接做年代趋势对照。
