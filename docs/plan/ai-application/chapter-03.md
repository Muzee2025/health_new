# 第三章 市场分析

> owner: CH03 ｜ version: 1.0 ｜ status: 冻结待Lead统稿 ｜ updated: 2026-10-27

## 3.1 市场规模与服务需求

我国高校与中学教育覆盖面广，为学校心理健康教育和支持服务提供了明确的潜在应用场景。教育部《2025年全国教育事业发展统计公报》显示，全国共有高等学校3167所，其中包括普通本科、职业本科、高职（专科）及成人高校；普通、职业本专科在校生3953.96万人。普通高中1.61万所、在校生3039.50万人；初中5.16万所、初中阶段在校生5509.34万人。[教育部2025年统计公报](https://www.moe.gov.cn/jyb_sjzl/sjzl_fztjgb/202607/t20260706_1442870.html)

上述数据描述教育供给和在校生规模，不等于心理服务需求人数、测评覆盖率或可采购客户数。高校总数含成人高校，而3953.96万人仅为普通、职业本专科在校生，统计范围并不完全重合，不能相除推算校均人数；普通高中和初中学生数按学段统计，包含一贯制、完全中学等学校对应学段。故本项目以学校业务需求和实际采购条件判断可服务市场，不将教育规模直接换算成销售额，也不重复使用第一章的心理问题流行情况数据。

需求正从一次性筛查延伸到结果解释、持续关注、人工复核和必要转介。学校需要在尊重学生知情与隐私的前提下，形成测评组织、异常线索复核、咨询预约、服务记录和管理汇总的工作闭环。项目的差异化方向是以平台承载流程与留痕，以规则辅助信息整理和持续监测，并将专业判断及支持交由合适人员完成；AI不得被表述为诊断者或自动危机判定者。现有采购公告呈现了单项测评软件、综合系统以及区域“测评+专业服务”等不同形态，说明采购范围差异显著，不能据此构造同质均价或市场收入。

## 3.2 目标客户、任务与进入条件

项目优先面向高校场景验证。高校心理中心、学生工作部门可提出业务需求，信息化、安全、采购及财务部门参与方案评审或采购；学生是主要使用者，心理教师及咨询人员承担解释、复核、咨询和转介。系统需围绕测评组织、预约、个体服务跟进、有限权限下的趋势汇总等任务设计，并先确认量表版权与适用范围、校内数据治理要求、接口与部署条件、运维责任及采购预算。项目目前是高校心理健康服务原型；尚无获批试点、正式合同或可申报的客户承诺，相关信息须由校方后续确认。

初中、高中是相邻但独立的拓展市场，不应把高校流程直接复制到未成年人场景。教育局、教科院或学校可能分别承担区域统筹、采购和校内落地；教师任务包括组织教育支持、识别求助线索、培训与转介，学生侧则应避免标签化和不必要的信息暴露。进入条件包括年龄适配的工具及使用依据、学生告知与自愿参与安排、适用时的监护人流程、角色权限、最短必要留存、人工复核和转介责任，以及区域采购范围、样本和验收边界。现阶段项目没有中学版本、家长端或获批中学试点；不宣称已适用于未成年人或已完成相关合规审查。不同学段任务及进入条件见表3-3。

## 3.3 采购证据与市场判断

公开成交案例只能证明具体项目进入成交环节，不能证明履约验收、持续使用或服务效果。四川邮电职业技术学院采购一套测评系统，成交11.47万元；中国劳动关系学院45万元采购包含访谈测评、职工场景适配、陪伴、培训、管理平台、干预练习及部署等综合内容。两者的标的范围不同，不能直接作为同一类产品的价格对照。龙泉驿区项目65.3万元由测评和筛查后干预两包构成，测评包约覆盖8.5万名学生并含档案、培训，干预包则含不少于1600人入校访谈和不少于300人个体咨询；成都市教育科学研究院96.5万元项目面向不少于20万名抽样学生，并包含测评、分层分析报告和转介通道。这些项目均不能换算为单校软件单价、每生价格或全国市场均价。采购公告来源见表3-2

因此，项目市场测算采用条件变量而非未经验证的金额结论：可服务采购单位数须按地区、预算、既有系统、服务能力和准入条件筛选；单项目价值须按软件、部署、运维、专业服务及合同期限明确范围，并采用实际成交或合同口径。当前无可靠依据填写全国渗透率、统一客单价、收入预测或市场份额。后续应以经校方确认的试点范围、采购需求、专业与信息安全审查、人员及预算安排逐步验证市场进入可行性。申报材料中的团队、导师、周期、经费及校内责任人字段继续留待用户后期填写，不以案例金额替代项目预算。
