# 六、项目预算与预期成果

## （一）团队分工

项目由研发、数据治理、专业审阅、校内业务和运行维护等角色协作完成。研发团队在现有工程基础上完善原型、权限流程、图表分析、隔离测试和操作文档，并对每项结果保留可复查记录。数据治理人员由校方指定，负责明确数据字段、用途、访问范围、留存删除和事件处理要求。心理及相关专业人员审阅测评工具的适用范围、结果说明、案例和人工承接方式；校内业务负责人确认服务流程、角色职责和求助转介安排。信息化与安全人员检查部署、身份权限、日志和备份恢复，运维人员依确认的职责处理监控、故障和恢复演练。团队成员、导师及其具体分工由项目负责人核实后填写，校内职责不由开发人员代签。

## （二）预算测算

预算按实际用量和经核实的单价测算。负责人依据学校财务要求补充数量、单位、单价、税费、报价日期、资金来源和配套依据；人员、导师、项目周期及金额均待后期填写。下表为估算科目，不表示采购或资源已经落实。

| 预算科目 | 测算方式 | 金额 |
| --- | --- | --- |
| 算力与API | 按经确认的实例时长、调用量及并发需求，结合有效报价核算 | 【后期手动填写】 |
| 部署、存储与备份 | 按批准的实例、使用周期、存储流量及备份恢复用量核算 | 【后期手动填写】 |
| 工具授权与专业评审 | 按所需授权材料数量、评审场次和学校核准标准核算 | 【后期手动填写】 |
| 数据质量与AI评测 | 按数据整理工作量、案例数量、评审轮次及必要资源核算 | 【后期手动填写】 |
| 测试与运维 | 按测试和恢复演练次数、维护工时及监控资源核算 | 【后期手动填写】 |
| 培训与材料 | 按培训场次、参训范围及材料制作数量核算 | 【后期手动填写】 |
| 合计 | 各项核准金额汇总，按申报模板复核 | 【后期手动填写】 |

服务器、场地或人员投入如作为配套资源，应由提供方确认并留存依据。报价或用量暂缺的项目先保留待填，核实后再汇总，不以推测金额替代。

## （三）成果与检查方法

项目计划形成一套可复查的工程原型，包括权限矩阵、数据统计与图表、经后续确认后开展的AI辅助分析、评测记录，以及操作、数据治理和恢复文档。工作以现有工程为基础，新增能力按阶段完成；合成案例用于演示和评测。AI相关材料记录数据统计结果、摘要草稿、人工复核意见及评测过程，不把模型输出作为诊断或自动处置结论。

每阶段都保存输入范围、软件与案例版本、检查记录、失败项和待处理问题。功能检查覆盖授权与撤权、审核、答复、跟进、导出和故障回退；数据检查记录完整、缺失、重复或冲突及其处理，不以记录行数代替人数。AI评测使用固定案例和统一量表，记录字段符合情况、边界拒答、事实核对、响应时间和成本，并由评审者记录意见与分歧。调用统计以本轮发起的全部调用为总分母，成功、超时、失败和取消分别计数；可评分比例另以实际完成且可评价的调用为分母，排除项需注明原因。业务可用性检查在相关工作获准后进行，记录任务完成情况、理解、耗时、人工承接和退出体验。目标值由校方与专业人员结合方案确定，当前不预设提升率，也不据此宣称测评准确率、心理疗效或服务效果。

## （四）阶段任务与交付

| 任务 | 交付 | 检查方式 |
| --- | --- | --- |
| 梳理责任、数据与工具 | 角色分工、字段用途说明、工具清单和人工承接流程 | 由对应业务、数据和专业人员逐项确认，记录需补充内容 |
| 完成隔离原型 | 合成数据演示、权限与业务流程、问题清单及恢复记录 | 在独立环境复验主要操作、异常处理和恢复过程，并保存测试结果 |
| 整理评测材料 | 案例版本、统计与摘要草稿、人工复核记录、评测结果 | 对照固定案例核查输出和失败分类，复核分母、版本及意见记录 |
| 准备试用与运行材料 | 经确认的操作说明、任务观察记录、运维与交接文档 | 按实际批准的环境和流程检查任务、人工承接、问题处理和退出方式 |
| 完成部署与持续维护准备 | 部署配置、监控及备份恢复材料、维护安排 | 在目标环境检查安全配置、异机恢复和运维责任，形成问题及处理记录 |

后续任务以前一阶段形成的记录为依据逐步开展；人员、导师、周期和资源未落实的事项按实际进度填写，不预设完成日期。

## 供Lead移入附录的说明

当前工程验证、真实服务使用、模型选择与调用、专业审阅、校内业务批准及生产部署分别属于不同事项。已有工程测试结果仅说明其对应环境和范围内的检查情况；不能替代稳定隔离环境复验、专业人员对工具与说明的审阅、校内对服务责任和数据处理的批准，也不代表真实模型已评测或生产环境已验收。涉及真实数据或外部模型前，应先确认提供商与模型版本、数据范围、保存和计费规则及授权；生产使用还需落实目标环境、安全审查、维护预算和值守责任。上述条件未确认前，项目工作保持在合成数据和隔离原型范围，相关服务与生产成果均列为后续工作。
