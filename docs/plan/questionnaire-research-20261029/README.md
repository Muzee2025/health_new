# 心理问卷选型与上线准备资料

> owner: A ｜ version: 1.0 ｜ status: 公开资料研究，待专业与校方选型 ｜ updated: 2026-10-29

本轮依据公开开发者/权利方说明、原始研究、法律及教育政策收集资料，覆盖高校和初高中场景。研究日为2026-10-29；学校所在地、服务主体、目标年龄、实际用途及供应商尚未确定，因此本包提供候选与实施依据，不指定一套可直接全校施测的方案。本轮没有采集答卷、复制整份问卷、导入业务库或修改运行系统。

## 一、目前最值得采用的准备路线

**先选用途和人群，再确认版本与权利，最后设计计分、人工服务和数据流程。** 建议先选择一个有明确服务承接的场景验证，不把问卷数量当成系统完整度。

| 场景 | 可继续评估的工具 | 选择前需解决的问题 |
| --- | --- | --- |
| 成年高校学生的症状筛查与跟进 | PHQ-9/PHQ-2、GAD-7/GAD-2 | 具体中文版本、目标校内人群证据、阈值与后续服务能力；短表不是自创删题版 |
| 心理健康教育中的幸福感/压力观察 | WHO-5、PSS-10；需要多维症状描述时再评估DASS-21 | 构念不同，不能相互替代；WHO-5商业用途限制、PSS许可请求和译本权利需明确 |
| 初高中学生的情绪行为或焦虑了解 | SDQ、RCADS、SCARED等年龄匹配版本 | 学生/家长/教师信息源、中文验证、电子许可、适龄告知与专业人员解释；不直接搬用成人阈值 |
| 已有SDS/SAS入口 | 先完成现有版本与计分审查 | 不因已有代码就默认授权、常模与适用年龄齐备；不能直接扩大为正式普测 |
| 睡眠专题 | PSQI作为单独专题候选 | 睡眠构念、近月回忆期、中文版本和实际用途许可；不作为心理疾病诊断 |

高校也有未满18岁的学生；初中与高中内部年龄跨度不同，必须用实际年龄分层。若暂未明确校园服务对象，不能提前指定全项目的唯一量表。

## 二、12组工具与权利线索

详细题数、回忆期、适用年龄、中文证据、计分/缺项未决事项见[工具研究表](instruments/instruments.md)。表内“候选”不表示已接入或获得全部用途许可。

| 工具组 | 测量内容 | 当前最直接的权利或证据结论 |
| --- | --- | --- |
| PHQ-9/PHQ-2 | 抑郁症状筛查 | Pfizer公布免费开放；具体中文题本一致性与用途记录仍需落实。高校研究支持进一步评估，不能据此定全人群阈值 |
| GAD-7/GAD-2 | 焦虑症状筛查 | 同系列免费开放证据；青少年结构效度与临床判别力须分别看待 |
| WHO-5 | 主观幸福感 | WHO 2024版为CC BY-NC-SA 3.0 IGO；非商业与商业用途要区分 |
| DASS-21 | 抑郁、焦虑和压力维度 | 开发者FAQ说明公有领域使用条件；短表计分转换和中文版本需固定 |
| SDQ | 儿童青少年情绪行为、多信息源 | 纸版和电子版权利不同；自行制作电子版须明确取得相应授权 |
| RCADS | 儿童青少年焦虑/抑郁维度 | UCLA提供多种版本，机构、研究、电子系统等用途需按其许可条件确认 |
| SCARED | 儿童青少年焦虑维度 | 已定位Pitt正式题本；简体中文版与电子/商业使用的权利链仍未核全 |
| PSS-10 | 主观压力 | 开发者CMU要求通过ePROVIDE申请；申请免费不等于已获授权或商业免费，译本权利另核 |
| PSQI | 睡眠质量 | Pitt拥有版权，实际用途、电子化/改动与商业条件需核；不因可下载就抄入平台 |
| SCL-90/SCL-90-R | 广泛症状清单 | 需辨认具体版本和权利人；SCL-90-R的出版社规则不能无差别套给所有中文改编表 |
| SAS/SDS | 焦虑/抑郁自评 | 现有代码使用的中文题本、计分依据与权利链尚待补齐 |
| BDI-II | 抑郁症状评估 | 出版社专业测验产品，须按正式中文版本、资格与许可条件审查 |

本包只保留来源、摘要和元数据，不分发题本或评分手册。某篇论文开放获取不意味着其使用的问卷、译本和常模可任意再发布。相关官方入口见[工具来源登记](instruments/sources.json)。

## 三、直接影响选型的研究比较

以下数值来自不同研究，不作合并、排名或本项目性能估计。阈值为各研究的结果，不是项目上线设置。

| 研究 | 样本与参照 | 研究报告 | 对项目的含义 |
| --- | --- | --- | --- |
| Zhang等，2013；DOI 10.1111/appy.12103 | 中国大学生959人完成问卷；研究采用SCID作诊断参照，摘要未明确每项访谈分母 | PHQ-9研究阈值11：敏感度0.89、特异度0.97；PHQ-2阈值3：0.81、0.96 | 具备高校中文验证线索，仍需读全文核对抽样、访谈流程和偏倚，不能写为系统准确率。[论文记录](https://pubmed.ncbi.nlm.nih.gov/24123859/) |
| Du等，2017；DOI 10.1111/appy.12266 | 一所大学邀请300人，230人完成在线问卷；81人接受MINI访谈 | PHQ-9研究阈值10：敏感度0.74、特异度0.85；AUC 0.897，95%CI 0.823–0.970 | 样本和访谈子样本较小；与上一研究阈值不同，不能归因于电子化本身，更不能选较好结果宣传。[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5580087/) |
| GAD-7中国青少年研究，2021；DOI 10.3390/healthcare9121709 | 67,281名10–17岁青少年；内部一致性、结构与PHQ-9相关分析 | 支持其在该样本的测量属性 | 与另一自评量表相关不是临床诊断参照；不能从大样本或高内部一致性推出个体诊断能力。[论文记录](https://pubmed.ncbi.nlm.nih.gov/34946435/) |
| Wang等，2025；DOI 10.1186/s12888-025-06754-y | 云南三地，首阶段15,368人；筛选阳性后访谈，最终2,237人进入分析，参照K-SADS-PL | 分析样本PHQ-9/GAD-7总体AUC分别0.664/0.669，分层结果亦不一致 | 这是条件筛选后的特定样本，存在外推限制；提示初高中需单独论证，也不能据此认定所有青少年场景都无效。[出版商原文](https://link.springer.com/article/10.1186/s12888-025-06754-y) |

原始研究的发表年和施测时间需分开；2025研究的上述云南调查发生于2021年。研究比较不能用作学校/地区心理风险排名。部分PubMed/PMC页面直开出现验证码或访问限制，已用出版商、正式论文索引与可读研究记录交叉定位；本包不是系统综述或全部中文验证研究的穷尽检索。

### 为什么筛查阳性不能直接当作患病概率

在预先确定的诊断参照和人群下，阳性预测值还受基础患病比例影响：

`PPV = Se × p / [Se × p + (1 − Sp) × (1 − p)]`

**仅作算术示例：**假设1,000人的真实患病比例为10%，敏感度85%、特异度90%，则真阳性85人、假阳性90人，175名筛查阳性者中约48.6%符合假设的诊断参照。其余90人是该参照下的假阳性，仍可能需要支持。这里的p、Se、Sp均为人为设定，不来自项目或目标学校，不能据此预测业务人数、定阈值或计算收入。

## 四、学校组织测评的近期政策

教育部《进一步加强中小学生心理健康工作十条措施》（教基厅〔2025〕2号）的测评安排与2026—2030年儿童青少年“五健”促进行动应纳入后续学校方案核对。前者提出统筹规范测评，每名学生每学年接受心理测评一般不超过1次；这需要在设计初高中组织施测频率时专门核对，不能将其简单解释为禁止所有专业随访，也不能直接套作高校统一规则。后者强调心理服务、分类干预与隐私保护。[教育部文件官方转载](https://app.www.gov.cn/govdata/gov/202510/24/538914/article.html)、[国家卫健委文件](https://www.nhc.gov.cn/fys/c100078/202512/9c3da4badfb34026b5fabbf5853105ee.shtml)。

2023—2025年专项行动计划可作为历史政策背景，不能继续把其计划期写成2026年的当前周期。完整条款、分龄同意、PIPIA、模型供应链和人工承接依据见[治理资料](governance/governance.md)。法律适用由学校根据处理主体、目的和实际链路确认；研究材料不代替个案判断。

## 五、项目后续上线前的工作包

| 顺序 | 工作包 | 应留下的可检查材料 |
| --- | --- | --- |
| 1 | 确定场景和校内负责人 | 实际年龄/学段、用途、服务容量、人工责任与学校流程，不先填虚构人员或时限 |
| 2 | 确定具体问卷版本 | 授权或明确允许使用的证据、原版/译本、适用人群、计分/缺失规则、阈值与说明审核 |
| 3 | 完成数据与运营设计 | 分龄告知、适用同意、PIPIA、访问/导出/留存/删除、供应商与模型传输边界、风险响应SOP |
| 4 | 在新隔离环境验证问卷模块 | 服务端权威计分、版本保存、边界/异常答卷、草稿退出/清除、权限和人工通知演练 |
| 5 | 验证AI辅助解释 | 只使用校验后的事实与批准资料；固定模型/提示/知识版本，独立评价无依据断言、遗漏、引用和失败退回 |
| 6 | 按实际任务决定试点与效果研究 | 学校/专业/隐私/技术/运营分别确认；需科研或伦理审查时按实际制度办理，不能以技术演示替代 |

可直接填写的[上线准备清单](launch-checklist.csv)与[问卷登记模板](questionnaire-register-template.csv)随包提供。当前源码的9项具体观察见[代码差距盘点](code-observations.md)，包括客户端计分、版本缺口、草稿持久化和敏感条目承接。本文没有执行其中的代码或数据库改动。
