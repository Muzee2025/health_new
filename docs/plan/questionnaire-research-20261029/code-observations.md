## 已有内容

`src/data/tests.js`包含SDS、SAS及两个趣味工具。按当前文件题目对象行静态计数，SDS为20题/10个反向题，SAS为20题/5个反向题，MBTI标签工具28题，MentalAge标签工具15题。这仅说明当前代码内容，不证明它们是正式授权版本或其计分正确。

学生端有逐题作答、返回上一题、断点恢复、结果及AI解释入口；后端有提交与历史记录结构。当前部分统计路由明确筛选SDS/SAS，不能据共用提交结构推断所有统计都混入了趣味测试。
