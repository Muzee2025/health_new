# 心理问卷选型与许可研究（公开来源快照）

检索日：2026-10-29。此材料为面向后续高校及初高中方案的研究输入，不是临床建议、诊断规范或部署许可。引用编号见同目录 `sources.json`。没有证据的许可和计分信息均标为待核实。没有复制任何整份题目。

## 选型判断

成人高校场景可将 PHQ-9/PHQ-2、GAD-7、WHO-5纳入候选评估。初高中场景不应默认套用成人PHQ/GAD阈值或判别能力：虽有中国青少年结构/相关性证据，2025年临床筛查研究报告表现不佳；该研究纳入2237名第一阶段自填筛查阳性并接受金标准诊断者，来自云南三个点位，并非完整人群随机验证队列。作者指出阳性筛选可能影响特异度；单省、年龄10–17及部分亚组样本也限制外推。青少年可另评估SDQ多信息源、DASS-21情绪维度、WHO-5幸福感及RCADS/SCARED焦虑工具，但均需核对特定年龄、中文版效度及许可。DASS-21不等同诊断；PSS-10测主观压力，PSQI测近一个月睡眠，不应替代心理症状筛查。[S03–S10,S12–S23,S33–S36]

这些建议是候选顺序，不代表已获学校、研究、电子部署或商业使用授权。系统化收集未成年人敏感健康信息，须先确定告知同意、家长/学生适龄同意、危机响应责任、访问控制、保留期限和转介能力；量表分数不能自动诊断或自动作出处置。

## 跨量表边界与上线前核查清单

1. **区分测量属性与诊断效度。** 内部一致性、结构效度、与另一自评量表相关，不能证明对临床诊断的敏感度/特异度。PHQ-9/GAD-7在中国青少年有大样本结构/相关性证据，也有2025诊断筛查性能不佳的反证，故必须呈现双面证据。
2. **不跨年龄复用阈值。** 阈值受年龄、样本构成、访谈标准、患病率、应用目的和后续服务能力影响。PHQ大学生研究阈值11与在线小样本阈值10各自成立于不同研究条件；不能归并成全校统一界值。小学、初高中、大学及成人分别验证。
3. **不把筛查当诊断。** 对任何高分、风险条目和自伤条目，必须有人工评估、可执行的及时响应机制和清晰责任人；没有响应承接能力时不宜启动主动筛查。
4. **按实际部署情境核实适用条款。** 纸质非商业研究、校内电子问卷、向学校收费的服务、商业赞助研究、公开网站、翻译/改编、保存题目/评分算法、EHR或后台评分，可能涉及不同条款。PHQ/GAD官方公告明确免费开放且无需版权限制，不能把电子部署另列为已证实的付费许可障碍；对特定译本、改写及具体服务模式仍应核对正式来源条款。其他量表依各自权利人规则执行；未取得明确许可证据的不能靠“免费可下载”推导所有用途获准。
5. **上线前补齐版本证据。** 记录题本版本号/发布日期、准确语言（简体/繁体/地区词汇）、版权行、回忆期、答案标签、反向题、缺失题规则、分数转换、阈值来源及原始验证人群。进行认知访谈和技术等值测试时不得改题后继续沿用原版效度主张。
6. **未决优先项。** SCARED简体中文版及电子部署授权、PSS-10在中学样本的证据与译本许可、PHQ/GAD特定简体中文版本文本和当前来源条款、SAS/SDS权利路径、SCL-90-R与BDI-II中文正式版/商业和电子许可均待核实。WHO-5商业用途需要许可；SDQ电子化明确需授权；RCADS研究/机构用途需书面许可；PSQI商用和修改明确需授权。
