本文是交付评审用草案，尚未作为已生效政策或完整法律合规结论发布。正式运营主体、联系人、保存期限与模型提供方待填写并核验，不能直接把占位内容当正式用户告知。

## 服务与人员

心域智链支持心理测评、科普阅读、AI对话、预约、学生留言和教师处理记录。AI输出和量表结果供理解与人工核实，不作为疾病诊断或治疗决定。学生留言由当前明确分配的教师处理，具体服务时间、响应方式、替代求助渠道由学校公布；系统不承诺自动联络或全天候人工响应。

运营主体：【待确认】；校内服务负责人及时间：【待确认】；数据与隐私联系人及办理方式：【待确认】。涉及紧急情况的实际服务安排由学校确认，本文不编造电话号码、人员或转介流程。

## 数据如何使用和可见

| 数据 | 当前用途和访问边界 | 正式运营前需确认 |
| --- | --- | --- |
| 账号、姓名、学号等资料 | 登录、身份与师生分配；公开注册仅学生，资料中的辅导员姓名不自动授予权限 | 必填项目、真实性校验、教师开通/停用责任 |
| 测评和报告 | 学生查看本人结果，教师只能按明确分配范围查看获准内容 | 量表来源/许可、适用人群、解释规则与具体可见字段 |
| 学生留言与教师答复 | 学生本人和当前分配教师可按权限访问；系统保留答复处理者与时间 | 响应时间、撤回/关闭规则及分配变更后的承接人 |
| AI聊天 | 正常模式保存会话；匿名开关改变会话保存行为，但请求仍经认证，启用外部模型时可能传输必要内容 | 各提供商、传输内容、保存条件与用户选择机制 |
| 树洞 | 界面显示匿名身份；平台仍有关联账号，明确分配教师可获得相应汇总，匿名展示不等于平台不可识别 | 社区可见范围、举报、下架、申诉、教师可见字段 |
| 预警审核及跟进 | 教师保存审核结论、原因和本人跟进任务；内部工作备注不作为学生端公开答复 | 复核责任、升级渠道、保留与更正办法 |
| 上传和导出 | 业务文件沿受保护下载链路，教师单生导出限定该生与当前分配；下载到个人设备的副本由接收方按制度保管 | 文件保留期限、设备管理与传播限制 |

学生端“分享”当前是系统文字分享或复制页面地址，不给第三人自动授予报告访问权。受控分享、到期和撤销功能没有完成前，不把它宣传为授权分享报告。

## 保存 更正与删除申请

保存期限表需由校方逐类确认，当前未获得批准期限。需要更正账号、撤销分配或申请删除时，由身份核验后的校内负责人受理，记录范围、决定和结果；申请受理不等于已经从所有备份及提供商删除。

审核事件按追加方式记录，不能从业务页面覆盖为另一种结论。更正、保留、去标识和合法删除之间的冲突应由校方制定流程；技术人员不因一条申请擅自删库、清表、补绑未知历史记录或修改审计。

评测和展示默认使用确定性合成数据。真实研究、宣传截图、模型训练或向第三方共享不因普通登录而自动获得授权，必须明确范围、用途、参与选择与责任人。

## 校方确认清单

正式主体、服务时间与支持渠道；数据类别和最少必填；模型提供商与数据处理条款；教师可见范围；保存与备份期限；更正/删除/退出办理；社区治理与申诉；事故响应和告知责任；告知版本、发布日期与确认记录。
