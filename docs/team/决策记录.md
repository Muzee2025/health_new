## ADR-001：项目名称

- 状态：已记录
- 背景：代码与当前工作约定采用「心域智链」作为项目名称；历史材料中存在旧名称。
- 备选：继续使用历史名称；统一当前名称并保留历史原文。
- 决定：当前项目名称统一为「心域智链」。归档文档中的历史名称仅作为原文保留，不改写历史标题或内容；对外新材料使用「心域智链」。
- 影响：README、快速启动及新建团队文档按当前名称表述；历史归档文件标注原路径和历史属性。
- 回滚方式：如负责人决定更名，更新本 ADR 和当前入口文档；历史原文仍保留可追溯。

## ADR-002：部署目标与数据保护

- 状态：目标已记录，尚未实现
- 背景：项目计划面向校内 Linux + Docker 环境部署，当前仓库尚未完成该目标。
- 备选：继续以本地开发为阶段目标；将校内 Linux + Docker 作为目标并分阶段补齐部署、安全和运维能力。
- 决定：目标环境为校内 Linux + Docker，当前明确标记为未实现；上线判断须以代码、运行记录和门禁证据为准。
- 影响：本轮 W0 只建立文档基线，不宣称已可上线；保留数据库、上传文件及本地运行目录，不删除或覆盖；本轮不改业务实现。
- 回滚方式：若目标环境调整，由负责人修订 ADR 和部署计划；保留现有本地数据及运行目录，迁移完成前不清理。

## ADR-003：W1 素材库范围与门禁

- 状态：依据用户“开始下一轮工作”完成W1，G1素材库技术项通过；真人分工信息与签字仍待补，不代签。
- 背景：主提示词 G1 同时要求先建素材库、禁止提前改页面样式，以及页面全部色值和外链清零，验收顺序存在冲突。
- 决定：W1 验收新素材、token、图表主题、manifest、许可、展示页、PPT 素材包与改造前截图。W2 再迁移现有页面；不以页面尚未迁移阻塞素材库建设，也不宣称这些现存问题已经消除。
- 模型：前端设计与素材由 gpt-6.1-sol 执行；清单校验、盘点与独立复核使用 Luna。
- 许可：新制作的几何/图形素材记录为项目新作；既有来源不明图片单列为待核实遗留素材，禁止纳入新素材包或假定可商用。
- 验证：展示页只使用本地素材；页面基线截图通过浏览器内合成 API 响应生成，不连接真实后端，不读取真实账号或学生数据。截图明确标为合成数据的当前前端基线。
- 影响：本轮不导入新全局样式到业务入口，不改后端及依赖版本；保留 legacy 素材的现有引用，迁移前不移动或删除。
- 回滚方式：W1 独立本地提交，可逐提交回退；原始 W0 基线仍保留。
