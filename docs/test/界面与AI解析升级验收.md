## 完成的改进

| 链路 | 本轮行为 |
| --- | --- |
| 测评界面 | 说明→可退出的逐题作答→服务器结果→结构化说明；进度、键盘选择、移动布局、保存失败重试、来源和局限均有状态。长版本记录折叠展示，MBTI不显示兼容用100分占位 |
| 可信提交 | 只接受四种当前工程登记类型、0-based原始选项与submission_id；服务器校验题数/键/选项类型、反向计分和换算，拒绝客户端分数/等级/额外字段。SDS/SAS仅数学计分，正式资格和解释仍待专业复核；趣味结果不进正式风险统计 |
| 当前答卷解释 | 必须传本人的test_id；找不到/越权404，不回退解释旧答卷；前端核对返回ID，保存失败不能请求解析，过期请求取消或忽略。输出摘要、观察、下一步、局限和计分来源 |
| AI与本地说明 | 默认明确标识local_rule/local_rules，无配置也能查看本地支持性说明；外部文本路径需显式启用，假客户端测试成功/失败/非法JSON与元数据。解释输入不发送逐题选项、姓名、学号、联系方式或树洞原文 |
| 草稿与身份 | 答案只存sessionStorage，校验身份/工具/版本/24小时期限/选项；清理旧localStorage草稿，登出和身份变化清理。浏览器存储不被描述为加密或共享设备安全保证 |
| 对话报告 | 只按当前用户、全局时间排序的真实记录汇总；空日期null不补零，不制造五维/疾病概率/热图或固定7点。来源、降级、资料不足和历史未核验明确显示；缺失字段不画成0 |
| 报告查询 | 限次退避GET轮询、每次处理只触发一次POST、离页取消；后端不重复排队执行同一用户的在途任务。空解释不再永久“生成中” |
| 教师界面 | 保留可信分配范围、预警/回复/跟进；不从情绪标签推导临床红黄绿，不按客户端阈值预填干预级别；未知预警等级显示待核验 |
| 危机提示 | 移除无法核验的号码和24小时/老师正在等待承诺。warning_state只表示预警是否保存，不能代表教师已接收或处置。普通/流式持久化失败回滚；流式仍保留支持文案及未保存状态 |
| 内容与数据 | 树洞帖子/规则摘要同事务；红能量不随机造历史；移除特定姓名/日期放大历史趋势；旧记录版本未知时不假补版本或当作当前规则结果 |
| 可选RAG | 编辑变短/清空时删除旧片段；失败文档本进程不继续返回旧索引。保持默认关闭、无自动模型下载；不宣称已完成跨进程发布/撤回一致性 |

多模型融合旧实现会为缺失视觉/语音及未执行步骤补默认置信度，本轮**停止通过业务API启用这条实验链路**：health能力false，submit在入队前503。独立的单次测评文本解析继续可用。保留内部研究代码与其历史测试，不将其静态融合结果当成实际多模态成果。

图片入口原先未解析内容便返回占位情绪特征，现保留身份/大小/类型校验后明确503不可用，不返回伪造特征、不保留文件。该最后收口有独立专项证据，不宣称已实现图像/音频心理分析。

## 中间失败与修正

- 后端首轮完整套件：187 passed/3 skipped/1 failed。唯一失败要求按特定姓名/历史日期放大情绪趋势。本轮删除该人为修饰后，将旧测试改为所有身份均保留实际值，保留失败日志。
- BE专项中间规则指纹序列化set失败、来源fixture未同步，修复后28项通过；执行者的阶段记录见[后端交接](后端AI解析修复交接.md)。Lead后续集成改了student/report，阶段hash不代表最终hash。
- 浏览器v1发现真实的首次键盘方向键定位问题，已修；同轮脚本还存在重复登录路由守卫、文章独立页面选择器错误。v2正常交互/页面大部分通过，5项脚本错误是过高文字长度阈值和文章同名h1/h2严格选择器，截图已目视核对并修脚本。
- 第一次48项浏览器检查43通过：错ID确已被拒绝，但脚本要求与产品不一致的固定错误原文，并未在失败时释放拦截器，造成后续404/回复用例级联失败。修为验证可见错误、其他答卷内容不渲染、finally释放拦截器，再按完整两视口执行，最终48/48；原日志保留。
- Playwright CLI离线不可用（ENOTCACHED），未安装依赖，改用仓库既有Playwright工作流和已装运行时。隐藏Start-Process启动被自动审批拒绝后没有绕过该动作，改用可控前台exec会话启动隔离后端；仍带出站阻断和独立目录限制。

## 复跑方法

所有命令从仓库根目录运行；不直接pytest，避免发现旧.env或旧库。

```powershell
.\.venv\Scripts\python.exe scripts/run-backend-baseline.py -rs
npm test
npm run assets:check
npm run assets:source-test
npm run assets:source-check
.\.venv\Scripts\python.exe scripts/check-repo.py --json
```

浏览器脚本为[scripts/verify-interface-ai.mjs](../../scripts/verify-interface-ai.mjs)，需要**已经准备好的全新QA库/合成身份**、loopback18081离线后端、不存在的新输出目录和tmp下的隔离生产包；拒绝仓库外路径和其他后端目标。不会创建真实账号、自动分配学生或切换业务服务。对代码测试是可复跑证据，不是现有服务迁移命令。
