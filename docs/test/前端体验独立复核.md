## 已核对事项

- `scripts/check-design-sources.mjs` 将素材库引用作为静态来源门禁；本次亲跑扫描 55 个文件、25 个图标、21 个已批准素材引用，结果 0 错误。新增业务页未见另建静态视觉源。
- 本次亲跑前端 Vitest：6 个测试文件、17 项通过；另亲跑设计源测试：7 项通过。命令使用仓库已有 Node 运行时，未安装依赖、未运行构建。
- 学生留言字段使用 `answer_text` 与 `response_state`；教师列表/答复与服务端字段一致。答复接口冲突返回 409 时提示刷新，学生端对 `unassigned` 明确显示尚未分配教师，且不承诺回复时限。后端 `backend/app/routers/teacher.py` 将答复限制于明确分配学生并以空答案条件原子更新。
- 教师预警审核历史按需加载；读取失败时页面明确说明不能据此判断有无审核原因。跟进摘要、完成结果和取消原因只在教师工作区渲染，操作字段与 `/api/teacher/follow-ups` 契约一致。后端个体 DOCX 导出经 `require_assigned_student` 校验。
- 文章正文使用 DOMPurify 清理；文章路由参数变化会取消旧读取请求，卸载时中止请求并清除重试定时器。教师/学生图表组件在卸载时释放图表实例。未发现新增依赖或锁文件改动；认证页仍通过动态路由加载。
- 先前发现的手机抽屉焦点入口问题已由 shell 修复：打开后跨帧查找并聚焦可见导航项，Tab/Shift+Tab 在导航内循环，背景 `.main-content` 使用 `inert`；Escape/关闭/导航链接点击/路由变化恢复触发按钮焦点，切换到桌面断点会关闭抽屉；卸载时取消尚未完成的聚焦请求。源码位置：`src/views/student/Layout.vue` 与 `src/views/teacher/Layout.vue` 的 `openMobileNav`、`closeMobileNav`、`handleNavTab`、`syncViewport`、`handleNavClick`。
