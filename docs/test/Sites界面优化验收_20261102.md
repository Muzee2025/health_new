## 修正与呈现

- 五维失败的直接原因是预览适配器遗漏`/api/v1/assistant/risk-factor`。现补齐与后端同义的不足状态：没有可核验的独立五维记录，正常空态不弹请求失败提示。网络失败保留局部重试，12秒超时；完整五维、0–100合法数值和非空文本来源才绘图。空白/null/伪来源/畸形返回不转为0。
- 首页行动区固定两列等宽，图标与文本有统一间隔；数据卡片按网格对齐、标题说明分层。留言页宽屏为并排的编辑与历史区，窄屏顺序排列。报告操作区对齐，未启用协同降为次级状态；空报告收敛为一张有行动入口的空态。
- 趋势默认近7天，支持7/30/90自然日；使用真实API的完整`date_key`，窗口内按最近已识别SDS/SAS工具单独统计，不混入其他工具或未知来源。展示有记录天数、均值、范围和首末变化；同日保留最后有效值、缺测断线，单日期不称存在变化，不作临床解释。
- 首页五项GET并行、按卡片加载与失败；ECharts按需要载入。报告主体不再等待可选模型/协同元数据，后者并发、各8秒超时；空报告不加载图表运行时。预览入口合并启动链并取消首次根地址的二次整页下载。
- 身份改变时销毁旧图表、清空打印载荷/快照、关闭对话框并取消在途请求；动态图表导入和打印准备前后校验身份/代次。原生beforeprint同步导出已经绘制的图，不依赖浏览器等待Promise。

设计细节见[首页记录](../design/首页分析与布局优化_20261102.md)及[报告/五维记录](../design/报告与五维状态优化_20261102.md)。
