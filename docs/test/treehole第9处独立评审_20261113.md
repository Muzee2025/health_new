- [student.py:1245](../../backend/app/routers/student.py#L1245) 对未查到的记录填 0，第 1248 行对未查到的点赞填 False，最终仍按先前加载的 `posts` 返回该帖。

**可达触发顺序：**

1. 用户 A 已收藏帖子 P；P 有 2 个点赞、2 条评论、2 条收藏，A 自己点过赞。
2. 请求 `GET /api/student/treehole/posts?tab=favorites` 已执行完帖子列表 SELECT。
3. 另一连接取消 A 对 P 的收藏并提交；这是现有 [toggle_favorite](../../backend/app/routers/student.py#L1301) 的正常删除及提交行为。B 的收藏仍在，点赞和评论没有改动。
4. 原请求继续读取互动信息。新版五次子查询都重新筛选 A 的收藏，P 已不在集合中，因此漏掉 P 的全部互动信息。

**独立复现：** 两个独立 SQLite engine 连接同一个全新合成库，在首条互动聚合查询执行前通过第二连接取消收藏并提交。记录此时读连接 `sqlite3.Connection.in_transaction == False`，确认仓库现有默认连接行为没有跨 SELECT 的 SQLite 读取快照。每个版本独立新建库，三个版本执行同样交错；原版与物化版相等，新版的等价性断言失败。
