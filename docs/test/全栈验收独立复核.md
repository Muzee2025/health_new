# 全栈隔离验收独立复核

> owner: Luna / W3-REVIEW ｜ version: 1.0 ｜ status: 本机隔离证据部分通过；目标镜像构建受阻 ｜ updated: 2026-10-24

## 复核范围

只读检查 `deploy/fullstack/`、空库初始化与SQLite备份/恢复工具、后端健康/鉴权/权限相关实现，以及 Lead 提供的隔离验收脚本、测试、配置差异和脱敏摘要。未读取 `.env`、数据库、密钥、真实账号或学生记录；未启动、停止服务/容器；未安装依赖或调用真实 provider。本文不替代学校生产批准。

## 独立结论

部署配置及验收边界经代码核对未发现尚未处理的阻断缺口。HTTP/TLS代理传输行为在缓存的 Nginx 镜像和合成后端上有独立运行证据；固定目标版本的全栈 Docker 构建没有通过，因此目标镜像的服务启动、HTTP/API、初始化及备份恢复验收仍未执行。当前结论为本机隔离测试部分通过，不能据此宣告全栈部署或生产上线通过。

## 已闭合的问题与未决门禁

早期Runner草稿会继承宿主`RUNTIME_ENV_FILE`等Compose插值变量；当前实现改成白名单进程环境，并有sentinel单测。早期非root检查与Nginx默认启动用户不匹配；Dockerfile现配置非root直接启动和临时路径。早期setup失败未单独记录的问题也已补setup阶段及无Compose调用时的`cleanup=not_needed`。这些均以当前文件版本为准，早期探针失败记录保留作开发过程证据，不覆盖最终通过的缓存代理探针摘要。

目标全栈镜像仍需在可访问目标镜像仓库的环境成功构建，并实际通过空库初始化、readiness、HTTP/API合成流程、SQLite备份与新路径恢复、容器健康/权限检查及清理。Linux生产构建、真实证书/DNS、防火墙、容量、异机备份恢复、业务责任人/隐私审查和试点批准仍未验证。本机或缓存镜像结果不得替代这些门禁。
