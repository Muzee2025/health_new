## 建库建议

建议 Lead 在隔离的交付目录建立独立 SQLite 资料库，不连写现有业务库，按来源类型分表保存：

- `source_files`：相对来源路径、SHA-256、来源类别、许可/出处和采集日期。
- `schema_tables` 与 `schema_fields`：导入字段字典及表级结构统计；将库间行数作为盘点元数据，不能当作样本量。
- `public_region_aggregates` 与 `literature_aggregates`：保留公开资料的原始分组口径、统计量、区间和限制说明。
- `training_examples`：本轮保持空表（0 条）；以后仅在实际存在且来源、授权、去标识和标签依据均明确的样本时导入，不用合成文本补数。
