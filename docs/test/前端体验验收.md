## 变更与边界

学生首页先给测评/预约/留言/助手入口，再展示原五类图表；教师首页先处理预警与跟进，再看趋势。导航保留六/五组，手机改抽屉，处理焦点进入/循环/恢复、背景inert、同页链接与断点切换。表格局部横滚、分页换行、表单/日期/弹窗按可用宽度布局。认证页统一标题和选填资料层级；文章详情补加载/失败/恢复，并中止过时请求和清理阅读量重试计时器。

所有静态素材、图标、字体、颜色与图表视觉仍使用已登记库；业务图表保留原数据、筛选与生命周期，不接合成图库数据。没有后端、数据库schema、API、依赖/锁文件、路由或素材源变更；不扩大教师权限，不提供虚构提醒/临床指标。404保留既有实现并纳入回归。

## 中间失败与修正

1. 基线首次构建在Git解压完成前启动，报找不到Vite入口；待解压完成后重跑成功，首个失败日志保留。
2. 初轮扩展探针发现手机聚焦在CSS可见状态生效前执行，独立Luna也发现背景可Tab。Shell补跨帧可见项聚焦、inert、焦点循环/恢复、可见关闭按钮和取消迟到任务，后续导航验证通过。点击当前路由也关闭抽屉。
3. QA脚本首次展开多个分组时使用会变化的nth locator，造成等待失败，改逐个选择当前折叠项；失败截图被计入页面数的问题改为只统计页面对象。学生详情当前高亮指向列表父入口，交互跳转后显式回到原路由，布局断言检查实际URL。这些脚本错误与真实页面缺陷分开。
4. release-qa核心38场景通过，但82扩展中9失败：学生首页grid最小内容宽、教师分页/日期/档案表单裁切。唯一owner分别修正，不靠全局overflow隐藏。accepted-qa余2项日期输入失败，另目视发现档案标题与导出重叠；按Element Plus实际内部结构和宽度变量修正，并加入120行多页分页与档案表单测试。
5. finalized-qa仍有2项日期输入失败；Lead实际DOM确认ElDatePicker多根节点没有父组件scoped标记，普通`.filter-date`规则未命中，实际仍350px。改为由有scope的父容器锚定`:deep(.filter-date)`及输入节点；专属popper样式让双月纵向排列并限制高度。实现者新Edge合成检查根268px/弹层296px且Escape关闭，Lead在新delivery-dist再跑完整UI/弹层验证。
6. 空表格提示由宽表居中改为手机可视区左对齐，排除LibraryEmpty，保持真实行横向滚动。最后生产包统一重建，最终完整结果另列，不用局部通过覆盖剩余失败。
7. verified-qa脚本38核心/92扩展/2趋势均通过，但Lead目视日期弹层下月底部出视口，旧max-height只减24px未计顶部偏移。Lead接管冻结后的专属弹层CSS，将高度上限改70dvh，强化垂直边界与实际滚至底部断言。新final-dist-v2完整重跑，先前脚本通过不能覆盖此目视问题。

原始`before/`、`after/`、`navigation-probe/`、`release-qa/`、`accepted-qa/`、`finalized-qa/`、`verified-qa/`与最终`final-qa-v2/`和各构建日志均保留。首次after探针为发现脚本等待问题而中断，只有部分截图，不声称完成整轮。
