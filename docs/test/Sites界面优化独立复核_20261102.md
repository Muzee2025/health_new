## 复核结论

此前复核发现的主要数据和身份问题均已由Lead修正，并补入定向测试：

| 原发现/复核点 | 最终静态结论 |
| --- | --- |
| 五维空值可能转成0、伪造来源对象可通过、畸形空响应被当作无记录 | 空白字符串、null、越界、非数值均不绘图；来源必须是非空字符串字段；`available + data:null` 和其他畸形结构显示格式错误；只有明确`empty`/`insufficient`状态才走相应空态；小写字段显式null不会回退到大写别名。真实0仍被保留。 |
| 五维图表惰性导入期间身份改变 | 图表渲染携带请求epoch和身份，动态导入后再次校验；身份改变会取消请求、清空旧数据并按新身份重新请求。跨标签和窗口重新聚焦也检查身份。网络失败显示重试；超时为12秒。 |
| 首页趋势无法读取实际后端日期 | 后端返回`date: MM-DD`与`date_key: YYYY-MM-DD`；摘要现优先用完整`date_key`，不猜短日期年份，并有后端形状测试。 |
| 首页趋势会混合SDS/SAS或未知工具、错误范围/零值处理 | 只纳入0–100之间的有限值；同一天取最后一条有效值，缺测保留null；按所选范围内最近一次已识别工具单独汇总，不纳入未知工具。没有已识别工具时呈空态。单条有效日期不计算首末变化，默认近7天。 |
| 报告切换账户后残留旧图或旧打印载荷 | 身份变化会中止报告、元数据、说明与协同请求，销毁ECharts/Chart.js实例，清空快照、打印载荷及已打开的预览/协同对话框；无报告时打印按钮禁用。打印准备流程在等待图表和绘制帧前后校验身份/epoch，载荷生成时再校验身份。 |
| 原生打印可能等待异步`beforeprint`导致图表竞态 | `beforeprint`现为同步逻辑，只导出现有已渲染图表；站内打印预览会先准备图表，等待绘制帧，再校验身份/epoch后生成载荷。 |
| 可选模型元数据可能阻塞报告首屏 | 当前模型与协同能力请求并行，各有8秒超时和AbortController；挂载时后台启动，不阻塞报告主体`fetchLatest`。失败时协同默认关闭。身份变化和卸载会取消元数据请求。 |
| 无对话报告显示空表和多个空模块 | 无报告时使用单一空态入口；对话源表仅在有行时出现并改为“本次报告依据的对话记录”。 |

首页趋势目前只提供描述统计（有记录天数、均值、范围、首末变化）及日期折线；说明将来源限定为服务器返回的SDS/SAS展示值，不把空缺补成0或转写为诊断、风险概率或因果结论。独立复核只检查实现和标签，不代表对这些指标的专业效度背书。
