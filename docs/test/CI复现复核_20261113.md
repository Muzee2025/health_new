## 6. 本机环境踩到的两个坑（与代码无关，但会污染判断）

### 坑 1：`git archive | tar` 在 PowerShell 管道里损坏

`git -c core.autocrlf=false archive --format=tar HEAD | tar -x -C <dir>` 报大量 `tar.exe: Damaged tar archive (bad header checksum)` 并无限重试。改用 `git clone --no-hardlinks` 后正常。**以后要 LF 干净树，用 clone 不用 archive 管道。**

### 坑 2：Python `tempfile` / esbuild 建的 0700 临时目录被文件权限挡住

未受限的沙箱模式下，进程用 `mode=0o700` 建的目录**自己列不出来**：

```
os.mkdir(p, 0o700)  → os.listdir(p)  → PermissionError: [WinError 5]
os.mkdir(p, 0o755)  → os.listdir(p)  → ok
```

后果是两个**假失败**，都不是代码问题：

1. `unittest discover` 22 个测试在 `TemporaryDirectory` 清理阶段抛 `PermissionError` → 报 `FAILED (errors=22)`，实际全部用例已通过（放行后同一命令 `Ran 55 tests, OK`）。
2. `npm run build` 报 `[vite:esbuild-transpile] remove ...\Temp\esbuild-xxx: Access is denied`，exit 1。把 `TEMP`/`TMP` 指到工作区内后 `✓ built in 8.86s`。

**规避方式（已在本轮全部采用）**：跑测试/构建前设 `$env:TEMP` / `$env:TMP` 指向工作区内目录，`PYTHONPYCACHEPREFIX` 指向工作区外缓存目录。**不要把这当成代码缺陷去改测试代码。**
