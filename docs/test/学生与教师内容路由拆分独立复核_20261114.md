## 路由顺序与前缀隔离

- `student_content.py` 将教师目录与文章分别放入两个 `APIRouter(prefix="/api/student")`。`student.py` 在原 `student_treehole.search_router` 后展平 `/teachers`，在 `student_report.router` 后、`student_treehole.router` 前展平文章组；这保留了原文件中两个不连续位置。
- `teacher_content.py` 使用 `APIRouter(prefix="/api/teacher")`。`teacher.py` 在 `_teacher_students_router` 后、`_teacher_profiles_router` 前展平内容/知识路由；`main.py` 对 student 与 teacher 父 router 均不再叠加路径前缀。
- 提交后的受保护快照仍以完整路径区分相同字面接口：student `/api/student/articles/page` 与 teacher `/api/teacher/articles/page`；学生与教师的文章、详情接口没有合并。
- 快照基线的 0 起顺序为 student `/articles/page` GET 第 21、`/articles/{article_id}` GET 第 23；teacher 对应第 55、57。teacher 内容/知识组接续为文章分页、文章列表、文章详情、文章创建、文章删除、知识 GET/POST/DELETE（第 55–62）。隔离运行的 `test_route_table_snapshot.py` 通过，验证完整 100 对路径与方法及注册顺序未漂移。
