# W2-LIB-03 素材引用独立复核

> owner: Luna ｜ version: 1.1 ｜ status: 独立复核通过 ｜ updated: 2026-10-22

## 复核范围

独立只读检查素材目录、资产解析器、图标目录、空状态包装组件、共享图表样式入口和静态来源检查器。没有读取 `.env`、真实数据库或服务，没有连接后端/API/外网，也没有执行构建。浏览器页面、生产态交互和图库截图另由 Lead 验证，本记录不代替那些证据。

目录将素材角色映射至manifest中approved项目；静态检查验证来源、许可、文件路径和哈希，并确认精灵symbol存在。资产URL由 `asset-registry` 统一解析，旧的未核实头像在打包glob中排除。图标目录限定精灵、审核素材和显式登记的Element Plus标准控件；业务页面不再自行导入图标包。显式图表选项经共享adapter，业务数据策略声明为 `business-api-only`。当前空状态页面经 `LibraryEmpty` 使用目录素材角色，检查器禁止页面直接使用默认空插画标签。此前发现的预约页 `arrow-down` 遗留标签已由实现方修复。独立复跑确认源码负例7项通过，素材完整性检查覆盖131/131。

## 动态内容与框架边界

静态门禁不限制来自已授权业务API的文章封面、头像上传、对话内容或图表数据；这些运行时内容应继续遵守各自业务权限与安全策略，不等同于仓库静态素材。测评项使用动态 `test.icon` 属性，但当前仓库数据值均为已登记的 `assessment`；运行时图标目录对未知名称抛错。`LibraryEmpty` 的 `role` 同样在运行时通过资产目录解析，未知角色会失败关闭。静态扫描自身明确声明不替代运行时动态键校验、图表语义检查、CSS布局检查或浏览器渲染。

Element Plus内部组件实现属于明确的框架边界：页面显式使用的独立图标由本项目目录登记；`LibraryEmpty` 传入已登记素材作为插画，但其包裹的 `ElEmpty` 仍会生成Element Plus自身DOM/内部结构。本复核不声称框架组件内部的所有图标或形状都已进入素材manifest。

静态检查是正则/文件扫描门禁，不是Vue AST审计。初次复核发现默认空态及图标标签规则可能漏掉PascalCase；实现方已将规则扩展到PascalCase与kebab-case，并加入 `CaseVariant.vue` 负例。本次复跑7项测试通过，覆盖已知大小写变体。动态绑定键仍需运行时验证；例如测评项 `test.icon` 与空态 `role` 不会被完整静态求值。当前测评数据使用已登记值，运行时目录对未知角色失败关闭。此静态门禁不应被描述为针对任意模板语法和任意运行时值的AST级保证。
