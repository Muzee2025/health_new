# W2 认证与权限加固

> owner: C / 安全实现 ｜ version: 0.4 ｜ status: 评审 ｜ updated: 2026-10-22

起点为 `62055a0`。本记录描述 SEC01–04 的实现契约与执行者自检；正式隔离测试和独立门禁由 Lead 及非执行者补充。没有读取或修改运行数据库、实际 `.env`、上传文件、提供商账号或 Git 历史，没有执行真实密钥轮换。

## 身份与兼容性

- `backend/app/security.py` 是唯一 PyJWT 签发/验证与身份依赖。固定 HS256，版本 `ver=2`、`type=access`、`iss=health-new`、`aud=health-new-api`，`sub` 是规范的正整数用户 ID 字符串，必须有 `iat`、`exp`；拒绝无版本、错误用途/主体/算法/时间的凭据。
- `routers/auth.py` 重导出同一个 `get_current_user` 对象，既有路由导入和测试的 `dependency_overrides` 继续有效。旧 `deps.py` 和 `utils/jwt_tokens.py` 已在核对调用方后删除，不保留开发 Header 或第二套解码器。
- 无版本旧 token 统一要求重新登录。HTTP 缺失/无效凭据为 401，权限不足为 403；用户不存在或角色不在 student/teacher 也拒绝。角色取数据库现值，不信任客户端或 JWT 中自报的角色。
- 保留用户名、姓名、学号的既有登录顺序和旧 bcrypt 密码兼容。仅新建账号执行密码规则：至少 8 个 Unicode 码点、含 ASCII 字母和数字、至多 72 个 UTF-8 字节。公开注册只能创建 student；教师创建学生必须显式给出 `initial_password`，不再以学号作为密码。
- 登录失败使用 IP 与身份的双维度计数；已存在账号的不同登录别名按同一用户 ID 计数。单账号 5 次、单 IP 20 次失败后在 15 分钟窗口内返回 429 与 Retry-After；注册也消耗 IP 预算。计数有锁、容量上限和过期清理，原始身份/IP不作为持久化记录。该防护限单进程，重启会清空，多进程/多实例需后续接入共享限流。

## WebSocket 与公开入口

- 浏览器握手改用子协议 `['access_token', token]`，URL 不携带凭据；服务端只回显 `access_token`，拒绝 query token。握手使用与 HTTP 完全相同的 resolver，避免旧代码数字用户名被错误解释为其他用户 ID。
- 无效/过期凭据或非白名单浏览器 Origin 关闭为 1008；连接最多保持到 token 到期。非浏览器客户端省略 Origin 时仍须有效的同一子协议凭据。连接日志不输出 JWT 或提供商原异常。
- `advanced_teacher` 的四个演示/导出端点增加 teacher 依赖，原真实 warnings 两端点继续已有的教师校验。`advanced_chat/chat/upload` 增加身份；两条 LLM fallback 入口增加身份；报告缓存全局指标要求 teacher。
- `services/llm_fallback.py` 提供纯本地规则函数。报告和后台分析不再无身份 HTTP 自调用本地 `/generate`，也不根据 localhost 放过接口鉴权。未配置外部生成地址或配置的是已知本地 fallback 地址时直接调用纯函数；显式外部地址仍按现有受控配置走原超时/降级路径。
- 报告/SSE原有本人会话/报告/协同任务检查保留。诊断只返回本人任务的状态/时间白名单，不返回全局任务映射、内部服务地址或提供商原异常；诊断不触发外部提供商探测。HTTP/SSE模型错误使用稳定码和通用文案。

## 上传、下载与日志

- 读取流按块限制到 5 MiB。PNG/JPEG/WebP必须后缀、MIME与基本文件签名一致，不接受 SVG、HTML 或客户端目录；PNG另限制 4096×4096。此为格式/边界验证，不声称完成恶意软件扫描或完整图片解码。
- 教师上传继续返回 `{url}`。明确公开图片随机命名后写入 `uploads/public_images`，教师头像限独立图片目录；聊天图片只校验与计算，不在本轮落盘。
- PDF/DOCX写入 `uploads/article_documents`，不进静态挂载；PDF验证基本头尾，DOCX限制成员数/路径/解压尺寸/压缩比/重复名，拒绝加密、符号链接、宏、嵌入对象、ActiveX及XML实体声明，校验包结构、XML和CRC，不执行文档内容。
- 文档下载使用 `/api/teacher/documents/{32位hex}.{pdf|docx}`。登录 student/teacher 可读取；禁止任意路径、符号链接及目录越界，使用 attachment、nosniff、CSP sandbox、private/no-store。前端使用 Bearer Blob 下载。
- `/static` 不再挂载整个历史 uploads，仅明确公开的两个图片子目录可达，且只允许 raster 后缀。旧根目录文件不删除、不迁移、不自动公开；既有根 `/static/文件名` 引用需要后续经过归类审核迁移，不能直接恢复整个目录公开。
- 合规导出使用每请求唯一文件名并在响应完成后清理新生成文件，限制图表数和图片大小；不覆盖共享导出文件。
- 移除向量召回的原 query、snippet/topk 内容及情绪/提供商请求响应原文日志，保留 trace、数量、耗时与错误类型；不以原始 SDK 异常作为用户 SSE 内容。

## 配置与上线边界

`JWT_SECRET_KEY` 没有开发默认值，必须由操作者生成独立随机值（至少 32 字节，拒绝重复/明显占位值）；认证服务缺配置返回 503，应用启动在启动回调前给出只含变量名的可读错误。Access token 默认 30 分钟，仅允许配置为 5–60 分钟。旧代码及示例默认 10080 分钟不再接受；这不是对实际 `.env` 内容的判断。

`CORS_ALLOWED_ORIGINS` 为逗号分隔的显式 origin，默认只含本地开发 5173 地址，拒绝通配符、路径或用户信息；部署需操作者给出实际 origin。`ZHIPU_API_KEY` 移除硬编码默认；未配置时不实例化有凭据客户端或发送空凭据请求，由原业务降级返回可读结果。

`.env.example` 只维护空密钥占位与非敏感示例；运行配置与历史有效密钥轮换仍由实际持有人处理。本轮不能据静态删除默认值宣布历史密钥已失效，也不能据本项宣布全系统上线。

## 执行者自检与待复核

已在根 `.venv` 的轻依赖运行自检，使用虚假随机密钥、独立内存 SQLite 和最小 FastAPI 应用，不导入生产 main：

1. 身份依赖对象相同、旧 bcrypt 登录、注册角色/密码拒绝、匿名 LLM 拒绝、HTTP/WS数字用户名一致、子协议仅回显标记、query token 1008、失败限流；退出 0。
2. DOCX路径/宏拒绝、PDF、SVG/伪图片拒绝、默认RAG禁用时路由轻量导入、纯本地fallback与全backend/app AST；退出 0。

## SEC05 阅读计数与入口请求体限额

文章新建从 0 开始。旧启动钩子及列表/详情初始化钩子保留兼容名称，但不执行查询写入或随机填充；NULL在响应中展示为0，实际阅读通过 `coalesce(views, 0) + 1` 原子递增，保留现有去重窗口。读取以当前数据库结果为准，避免进程缓存覆盖较新计数。没有修改或清零任何已有运行数据；旧存量计数含多少历史随机填充无法从现表追溯，不应当作可信独立浏览人数。

新增纯ASGI `UploadBodyLimitMiddleware` 在三个multipart路径（教师文件、教师头像、聊天图片）进入FastAPI解析前读取有界请求体，合计超过6 MiB立即413；包括无Content-Length和声明较小但实际超出的请求。Header只用于提前拒绝，不能跳过流量累计。只有合格请求重放原始分块进入multipart，未合格请求不调用下游解析器；不记录请求内容。该6 MiB为整个multipart包的限额，单个文件仍按前述5 MiB独立校验。


## SEC06 明确师生分配

用户已确认：教师只查看明确分配给自己的学生。新增 `teacher_student_assignments`，teacher_id/student_id分别外键到users，并对二者组合唯一；没有按advisor、姓名、预约、历史聊天或同班级推断归属。角色校验与查询均要求teacher/student现值正确；角色变化产生的旧错误关联不能获得访问。公开API不提供grant/revoke能力。

- 教师学生列表、详情、仪表盘、预警待办/审阅/全部warnings、审计列表/预览/Word导出、预约与干预均通过明确分配子查询。未分配的查询/修改统一404或空聚合，不先泄漏记录是否存在。
- 预约和干预还保留记录自身teacher_id限制；学生详情不返回其他教师的私有预约和干预。撤销分配后这些记录也不可见。
- 教师创建新学生在原事务中同时创建分配；已有学生必须由操作员显式grant，不自动导入历史关系。没有分配的教师获得空列表/真实零计数。
- 学生目录只提供教师公开字段，并增加本人关系的 `can_book`；无关系false，匿名false。预约必须已有明确关系，不因预约自动授予权限，未分配时提示联系学校操作员。
- WebSocket新预警广播必须显式传入db和student_id，发送前查询仍有效的分配与教师角色；无分配无收件人，不保留全教师广播后备。每次发送重新查询，撤销后续广播不再送达。
- `advanced_teacher`不再混入全局演示学生或学校大屏常量。source=assigned_students，data_status为measured/empty；消息、学生、会话及待处理预警来自当前范围。覆盖计数不是转化漏斗，缺乏可信楼宇资料时heatmap为空；情绪按实际有效样本取均值，无样本null并附sample_counts，不编造临床风险分。
- 审计调整仅提供经过归属检查的预览，明确persisted=false；没有虚称写入RLHF。导出只包括当前分配的真实预警，不包含全局mock记录。学生详情没有正式生成摘要时明确告知未生成，不返回“状态稳定”的演示结论。

离线工具仅支持显式选定的现存SQLite文件，不导入应用、读取环境变量或发现.env。以下命令为操作模板，尚未对运行数据库执行；实际持有人应先按运维流程备份并选定文件，不将占位路径直接当实际路径：

```powershell
python backend/migrations/20261022-student-assignments.py --database <explicit-sqlite-file> check
python backend/migrations/20261022-student-assignments.py --database <explicit-sqlite-file> upgrade
python backend/scripts/manage-student-assignments.py --database <explicit-sqlite-file> list
python backend/scripts/manage-student-assignments.py --database <explicit-sqlite-file> grant --teacher-id <id> --student-id <id>
python backend/scripts/manage-student-assignments.py --database <explicit-sqlite-file> revoke --teacher-id <id> --student-id <id>
```

迁移只增加关联表及索引，不修改已有users或其他业务记录。重复upgrade/grant/revoke幂等，角色验证、唯一约束和事务避免半完成写入。downgrade仅当关联表为空才允许移除新schema，非空直接拒绝，不能以“回滚”为由删除已有分配；users和历史记录不删除。工具限定SQLite，其余数据库不声称已提供迁移。

执行者在全新内存数据库、独立忽略临时目录、dotenv禁用及外呼拒绝条件下自检：两教师/各自学生/未分配学生隔离、跨对象404、真实零/当前范围聚合、Word不含他人学生、预约can_book与拒绝、WS广播撤销、CLI幂等和非空回滚拒绝，退出0；11相关Python AST通过。只验证临时合成数据，不是运行数据迁移或独立门禁。正式ACL测试由Lead安排非执行者执行后登记。


## T-DATA 显式空库初始化与无自动DDL

已移除 `main.py` 导入时的 `Base.metadata.create_all`。`database.py`不再发现.env，也没有隐式数据库地址：`DATABASE_URL`必须由操作员明确注入进程，缺失或驱动配置错误只报告变量名，不打印连接串。创建SQLAlchemy engine和注册路由保持惰性，不在import时建表或连接数据库。显式启动参数如何载入运行.env由Lead维护启动说明，本文没有执行该启动命令或修改运行.env。

新工具 `backend/scripts/init-empty-database.py --database <new-sqlite-path>` 仅创建全新空SQLite库：父目录必须存在，所有已有文件（包括空文件/符号链接）拒绝；通过xb独占保留新文件后，禁用dotenv发现，只设置所选文件的连接地址，再导入models创建新schema。创建失败保留新文件并给可读错误，不覆盖或删除用户已有文件。初始化不依赖JWT或提供商凭据。

空库初始化与已有库迁移严格分开：已有库只能采用经过审核的显式迁移，不能用初始化脚本覆盖。此处只产出工具；没有执行任何运行库初始化/师生迁移/分配。

执行者在全新忽略临时目录用子进程自检：新空库含users和分配表、已有空文件退出2且字节/修改时间不变、main import期间禁止Engine.connect仍成功且指定不存在的DB文件仍不存在、缺少DATABASE_URL清楚报变量名；退出0。测试禁用dotenv并阻断外呼，正式独立测试由Lead/Luna记录。
