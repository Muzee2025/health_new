# 高校两学期模拟库验收

本轮用户要求模拟约两万名高校学生在 2025–2026 学年两个学期的数据，包含时间、年级、学号，并参考武汉学院专业和学号结构。交付 [SQLite、三份 CSV 与数据说明](../../deliverables/心域智链_高校两学期模拟库_20261104.zip)。

武汉学院公开校历作为学期日期依据。秋季活动窗口 2025-09-06 至 2026-01-18，春季活动窗口 2026-03-07 至 2026-07-12。正式上课日分别为 2025-09-08 和 2026-03-09。2025 级秋季活动从 2025-09-13 起。院部设置、特色班和分年级专业以公开资料为参考，具体链接和编码见 [数据说明](../../deliverables/心域智链_高校两学期模拟库_20261104/数据说明.md)。

按本科大一至大四场景模拟 2022–2025 级同一批 20,000 人。专业权重和年级人数为场景参数，生成 8 个院部、41 个专业或方向组合、503 个班和 40,000 条人学期学籍。模拟编号沿用示例中的入学年、院部、专业、班序、个人序号布局，采用 `SIM-YY9CCPPBBSS` 虚拟命名空间。公共位含义未确定，选取 `9` 为模拟标记。提供的两条示例仅用于推断布局。学校未提供班号及分班清单，班级规模和编号均为模拟值。

专业采用参考子集。2025 级模拟采用 34 个组合，公开收费目录同级普通本科段列有 36 项，其中艺术与科技、供应链管理（数字电商供应链方向）留在参考范围。其余入学年分别选取 32、33、34 个组合。

| 学期 | 学籍 | 活跃学生 | 平台事件 |
|---|---:|---:|---:|
| 第一学期 | 20,000 | 12,348 | 115,275 |
| 第二学期 | 20,000 | 12,814 | 120,132 |

事件包括平台访问、文章浏览、打卡、演示测评、聊天会话、预约、树洞和教师留言。活跃学生在同一学期内按学号去重。人学期表含零活动记录，按事件类别求和可得到活动量，按类别汇总的活跃人数可能重叠。打卡和演示测评是演示数值，问答候选与事件样本按表分开。

[构建脚本](../../scripts/build-campus-simulation.py)以固定种子 20261104 生成。只读备份已核验的合成问答库，在独立数据库添加模拟表和分析视图。逐表对比原 11 张表全部行，96 条问答候选与 476 条资料保持原值。先前交付压缩包及三个登记原库与已有哈希一致。主仓库改动保留，模拟库用于离线分析。

验证命令在仓库根目录执行，Python 使用本机已装工作区运行时。

```powershell
python scripts/build-campus-simulation.py --source 'deliverables/心域智链_合成问答训练集_20261102/synthetic-training.sqlite3' --output 'deliverables/心域智链_高校两学期模拟库_20261104'
python -m unittest scripts.tests.test_training_database scripts.tests.test_synthetic_dialogues
python tmp/campus-simulation-20261104/verify-and-package.py
```

三条命令退出码均为 0。SQLite 完整性检查为 `ok`，外键异常为 0。年级、学号拆分、班级成员序号、两学期覆盖与活动时间窗检查均通过。三份 CSV 逐行与 SQL 查询结果比对，分别为 40,000、235,407、80 条。既有专项共 30 项通过。归档内六份文件逐一验哈希，压缩包 SHA256 为 `6bd81afd4ae4e74cab4d0331f90dbc48b000b0922136608956a0d2f14812939b`。

使用同一构建命令在 `tmp/campus-simulation-20261104/rebuild` 复建并退出 0，SQLite 与三份 CSV 的 SHA256 全部匹配。数据库命中既有 SQLite 忽略项，压缩包内包含完整数据库。团队记录的 `git diff --check` 退出 0。
