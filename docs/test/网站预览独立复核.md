# Sites 私有界面预览独立复核

> owner: 独立复核 ｜ version: 1.2 ｜ status: 最终窄改静态复核通过，v2平台验收待确认 ｜ updated: 2026-11-02

## 复核范围

只读检查本轮隔离副本 `tmp/sites/xinyu-preview-20261102`、`scripts/build-sites-preview.mjs` 及Lead提供的隔离浏览器证据。未启动本地服务、未重复构建、未访问已部署 Sites，也未操作原库、后端、环境配置或用户标签。本报告不构成复核者亲跑浏览器或v2部署通过证明。此前报告记录了 `window.fetch` 同源非API写入可能穿透；Lead随后修改该包装器，本轮对更新后的实际代码片段做了 stub 方法矩阵复核。

## 复核结果

| 项目 | 结果 | 依据 |
| --- | --- | --- |
| 原前端快照 | 通过 | `source-snapshot.json` 登记203个 `src/`、`public/` 文件；复算原文件与副本SHA-256，203项全部匹配，无快照外文件。 |
| 图表视觉来源 | 通过 | `chart-style.js`、`chart-options.js`、`chart-surfaces.css`、`chart-palette.json` 四个复制文件与原路径逐字节一致。 |
| SPA静态配置 | 静态检查通过 | 专用 `vite.config.js` 关闭环境目录读取；Sites 配置将静态目录指向 `dist`，并启用 `single-page-application` 回退。未验证平台实际部署行为。 |
| 合成演示身份与内容 | 通过静态检查 | 学生、教师及记录均使用 `DEMO`/“演示”标识；模型夹具明确标为未连接或预设回复，协同能力关闭，学生报告为空。顶部提示标示合成数据、保存和AI服务不可用，并要求勿填真实信息。 |
| Axios与API隔离 | 通过静态检查 | Axios仅允许同源GET/HEAD；写请求返回409，未登记的GET返回501。原生 `fetch` 对 `/api/` 与跨源请求返回503；WebSocket被关闭桩替代。 |
| 原生 `fetch` 写入边界 | 通过（stub矩阵） | 初次复核发现同源非API写请求会透传，作为阻断项交Lead。修订版先读取 `options.method` 或 `Request.method`，统一拒绝所有非GET/HEAD、所有 `/api/` 及所有外域请求。11项 stub 矩阵覆盖静态GET/HEAD、POST/PUT/PATCH/DELETE、API/外域GET、Request方法及options覆盖；符合预期。 |
| 文章搜索参数 | 通过静态核对 | `useArticleCatalog.js` 以 `q` 发送搜索词，合成分页夹具现从 `q` 读取；Lead交互日志记录了搜索、清空、文章打开成功。 |
| 教师仪表合成计数 | 通过静态核对 | 教师夹具 `uv: 1`，同时学生夹具有且仅有一个合成演示学生，指标与列表人数一致。 |
| CSP图片拖动属性例外 | 通过静态核对 | `script-src` 仍为 `'self'` 且未开放 `'unsafe-inline'`；仅 `script-src-attr` 使用 `'unsafe-hashes'` 与单一SHA-256。复算该值对应既有 Element Plus `ondragstart="return false"` 属性代码。Lead提供的预约页面CSP事件日志为空；此浏览器观察未由复核者亲跑。 |

Service Worker 静态检查未见 `fetch` 事件处理器；`main.js` 会注册它，但当前脚本只清理一个旧缓存并声明不缓存/重放API响应。CSP将连接、脚本、图片等限制为本源（图片另允许 `data:`/`blob:`），减少了意外出站面；这不能替代对 `fetch` 写方法的显式拒绝。
