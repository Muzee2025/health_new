## 范围与结论

任务 OPT-REVIEW。独立复核文章列表与内容管理页面、`ArticleCreate`字段校验、8篇使用指南、SQLite新库目录/导入工具及相关验收证据。未读取原运行库、`.env`、用户上传或真实账号；未访问真实服务、用户浏览器标签、真实模型或外部网络；未修改业务代码或执行Git操作。本文件为本评审唯一写入文件。

最终源码与合成测试未发现阻断性问题。文章浏览列表的搜索、分类、排序、分页、空态和错误恢复与当前API响应一致；教师创建文章时前后端均限制空白与字段长度，保存和删除操作能防止重复提交；正文保留换行并继续经DOMPurify净化。创建接口服务端将新文阅读量重设为0，不接收客户端阅读量覆盖。

内容导入工具默认只计划、不创建文件；`--apply`要求全新目标，可选来源只读并使用SQLite backup API复制。导入在目标库事务内进行；同标题且所有受管字段一致时跳过并保留原阅读量和创建日期，同标题内容不一致时回滚本次文章插入。工具不改原库，不新增schema表或业务接口。8篇指南把工程操作边界与医学、隐私政策审批清楚区分。

## 代码与内容复核

- 学生文章页支持标题/摘要/来源搜索、分类、最新或阅读量排序、每页12篇、清空筛选和缺失日期排序回退；请求有中止和15秒超时。分类消失时回到全部，分页变更后回到列表起始位置。教师文章页支持搜索、分类、分页和阅读入口；创建失败保留表单，保存期间禁改/禁关，删除确认打开时即锁定该行，避免重复删除请求。
- `backend/app/schemas.py`对标题、摘要、正文、分类、来源和封面字段去除首尾空白并执行长度限制，标题/正文必须非空；正文内部换行保留。`backend/tests/test_article_content_validation.py`覆盖非法字段不入库、边界长度、服务端视图数重置和权限拒绝。文章公开读取/view API及教师角色边界未在本轮改变。
- `backend/scripts/build-content-database.py`对目录字段、来源/封面、HTML标签/属性、可见文本、内容长度和项目内来源路径做校验；外部来源和未批准HTML拒绝。新库模式通过显式新目标和隔离子进程初始化schema；显式源模式拒绝源文件/目标复用，源以只读URI打开。SQL写入使用参数绑定和`BEGIN IMMEDIATE`，冲突失败回滚。`--verify`只读并输出完整性、外键违规数及文章数。
- 8篇指南覆盖心理科普阅读、留言、预约、测评结果、AI能力、教师跟进、隐私/匿名和账号安全。复核中把“提交成功后保存”的条件与测评失败提示对齐；教师内部跟进备注不向学生展示；匿名展示不等同后台不可识别；指南未编写诊断/治疗承诺、临床量表阈值、虚构来源、学校时段或隐私留存规则。`engineering_reviewed`仅表示工程核对，不是医学或机构审批。
