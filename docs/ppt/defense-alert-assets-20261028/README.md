固定种子20261028。数据人为设置120人存在重复睡眠困扰表达、80人明确希望老师联系，两组重叠40人。处理代码先去除精确重复、检查时间和文本，再以14天内至少两条不同记录出现“睡不好”作为重复表达演示条件，以“希望老师联系我”作为请求回应条件。其并集为160人。14天与这些表达均为流程说明参数，不是临床阈值；不得将160/1,000称作患病率、AI检出率或性能结果。

处理示例剔除结构化姓名、学号、占位联系方式及原始学生ID，以S编号组织必要记录；编号映射与虚拟教师分配留在受控侧。不是不可逆匿名，也未证明真实自由文本去标识能力。提醒携带原文依据记录ID，仅路由到场景中明确分配的虚拟教师。教师须结合原文、时间与语境核对，再决定重点关注、联系与跟进。100条缺失另建核对队列，不以缺失记录阻断人工求助。

S-0098有两次睡眠困扰表达及主动求助，对应虚拟T-DEMO-01；S-0142主动请求联系，对应T-DEMO-02。第6页展示的是由离线规则支持、人工编排的提醒示意，不是真实AI输出。AI拟进一步组织依据摘要，未调用真实模型或发送任何实际通知，也未建立真实师生分配。
