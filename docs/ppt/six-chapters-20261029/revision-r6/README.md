## 协作设计

协调器负责数据范围、任务状态和结果回收。语义智能体先整理带原文出处、时间、否定与不确定性的最小索引；其余角色只按任务需要读取片段，完整对话与身份映射不向各模型复制。情绪、认知、纵向三路共享依据，但不把另一角色的生成判断升级为原始事实。

风险角色核对各路描述性线索及其依据，资源角色基于已核对的信息形成支持性草稿。统一回传原文引用、任务结论、待核验项和完成状态。没有历史不补趋势，失败不补置信度，冲突回到原文核对，未决事项交授权人工。紧急线索在任一阶段均可经独立支线优先转人工，不等待普通链全部完成。

新增案例与中间输出均为虚构材料，不含真实学生或模型实测；认知表述仅为候选线索，不能定级或诊断。所有新增机制均标为设计方案，未改动当前业务实现；六模型协同入口仍停用。当前第9页的单次test_id说明与主动求助路径保持，不把本轮图表解释为自动向教师发送测评或AI结论。
