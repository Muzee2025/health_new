## 第9页项目原理

新增7个可编辑节点、6条原生连接，保留创新章节位置与三项创新主线。

1. 学生提交原始选项，服务器按题本版本校验、计分和保存，返回当前记录 `test_id`。
2. 仅按当前答卷事实生成说明，标明本地规则或模型来源；学生查看分值、建议与局限。外部模型需显式启用，不可用时保留本地规则说明。
3. 学生可自主另行留言或预约；不自动把测评或AI结论发送给老师。
4. 先校验明确分配关系，由对应教师人工核对和答复；需要时创建内部跟进任务，记录状态、结果和原因。
