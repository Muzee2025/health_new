# 18页逐页优化预览

> owner: A / Lead ｜ version: 1.0 ｜ status: 制作与核验中，供逐页选择 ｜ updated: 2026-11-01

用户确认针对当前六章PPT的每一页各做一张优化预览，不是分别重做15份历史PPT。本轮以2026-10-31最新18页稿为底稿，保持18页与六章顺序，提供优化参考稿、原页/优化页对照图与总览。原稿和用户选择保留的第2、3版模型示意图保持字节。

## 审阅约定

- MUST：18页逐页对应；主要事实、金额和原生数据不捏造；原始来源和原页文字保存在备注备查。
- MUST：每页有可独立审阅的优化图，原稿不覆盖；全部新增原生文字使用微软雅黑24pt，按加粗和布局组织层级；图内模型名/专家角色加粗并居中。
- MUST：统一引用既有素材与项目token；截图为原合成演示；题目、AI和试点的拟建状态保持，不把本地部署写成已实现。
- MUST：实际原生PowerPoint渲染并查看全18页，核对图表数据及图片比例；无证据的检查不称通过。
- SHOULD：用对照总览及离线索引方便用户按页挑选；重要内容保留为原生可编辑文本、流程和图表。
- NICE：说明每页改动和仍待用户选择的地方。

这是用户明确要求的探索审阅版本，不作为最终样式获批或正式发布。设计方向沿用本聊天白底、浅紫色、居中和清晰模型分工的偏好，不新增确认流程。素材来源和实际生成记录见[build-record.json](build-record.json)，源脚本为[build-page-previews.py](build-page-previews.py)，锁定的项目主题见[resolved-theme.json](resolved-theme.json)。
