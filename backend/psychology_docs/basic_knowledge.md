# 心理学基础知识库

## 1. 心理咨询伦理与保密原则
心理咨询师在工作时，应将保密视为最核心的原则之一。咨询中涉及的所有个人信息、对话内容及情绪状态都应受到严格保护。唯一的例外情况是：当来访者表达了明确的自伤、自杀或伤害他人的意图，或者涉及虐待未成年人等法律规定必须报告的情形时，咨询师有责任突破保密原则，启动危机干预机制。

## 2. 倾听技术与共情
非评判性倾听是建立咨访关系的基础。咨询师不应对来访者的情绪（如愤怒、焦虑、抑郁）做道德或对错的评判。
- **反映情感**：“听起来你因为这件事情感到非常挫败。”
- **内容释意**：“你的意思是说，最近的考试压力让你觉得喘不过气来，是这样吗？”
- **无条件接纳**：允许来访者在安全的环境里哭泣或发泄，让他们知道“有这些情绪是正常的”。

## 3. CBT（认知行为疗法）基础
认知行为疗法认为，不是事件本身引起了情绪，而是我们对事件的“认知（看法）”导致了情绪反应。
- **识别自动思维**：例如，考砸了一次就觉得“我什么都做不好”（过度概括）。
- **认知重构**：引导来访者寻找证据支持或反驳这种绝对化的想法，将“我什么都做不好”转化为“我这次没考好，但这并不代表我个人的全部价值”。

## 4. 情绪调节方法
面对急性焦虑或情绪崩溃，可以尝试以下实用技巧：
- **4-7-8呼吸法**：吸气4秒，憋气7秒，呼气8秒。重复四次。这能激活副交感神经，迅速降低心率。
- **着陆技术（Grounding）**：寻找周围环境中5个能看到的东西，4个能摸到的东西，3个能听到的声音，2个能闻到的气味，1个能尝到的味道。这有助于将注意力从焦虑的内心拉回现实当下。
- **安全岛想象**：在脑海中构建一个完全安全、放松的地方，想象自己身处其中，感受那种平静。

## 5. 危机干预话术
当来访者感到极度绝望或表达出消极意图时：
- **肯定求助的勇气**：“你能把这么痛苦的想法告诉我，这需要很大的勇气。我很感谢你愿意相信我。”
- **探索支持系统**：“在这个世界上，还有谁是你在意或者在意你的？哪怕是一只宠物？”
- **提供陪伴**：“现在的感觉一定像是在黑暗的隧道里，但我愿意陪你一起走这一段。你不必一个人面对。”
